# 顶级健身减脂全攻略

> 不节食 · 不挨饿 · 科学减脂 · 高效增肌

---

## 一、核心原则

### 🔥 热量缺口

减脂的第一性原理：**热量消耗 > 热量摄入**

- 建议缺口：300～500kcal/天（不影响代谢）
- 极端节食（<1200kcal）→ 代谢损伤 → 反弹更胖
- 每周减重：0.5～1kg 是最健康的速度

### 💪 力量训练保代谢

- 纯有氧减脂 → 肌肉流失 → 代谢下降 → 平台期
- **力量训练 + 有氧** 才是最优解
- 肌肉每增加 1kg，基础代谢多消耗 50～100kcal/天

### 🍽️ 饮食不挨饿

- 吃够蛋白质：1.6～2.2g / kg 体重
- 吃够膳食纤维：蔬菜不限量
- 碳水不是敌人，关键是「吃对时间 + 吃对量」

## 二、一周训练计划

### 推荐分化方式：推 / 拉 / 腿（Push / Pull / Legs）

适合有一定基础的训练者，每周 6 练，效率最高。

| 星期 | 训练内容 | 强度 |
|------|---------|------|
| 周一 | **推胸 + 三头** | 8～12RM |
| 周二 | **拉背 + 二头** | 8～12RM |
| 周三 | **腿部 + 肩** | 10～15RM |
| 周四 | 休息 | — |
| 周五 | **推胸 + 三头** | 6～10RM |
| 周六 | **拉背 + 二头** | 6～10RM |
| 周日 | **腿部 + 核心** | 10～15RM |

### 备选方案：上下肢分化（适合一周 4 练）

| 星期 | 训练内容 |
|------|---------|
| 周一 | **上肢推**（胸、肩、三头） |
| 周二 | **下肢**（腿、臀） |
| 周三 | 休息 |
| 周四 | **上肢拉**（背、二头、后肩） |
| 周五 | **下肢 + 核心** |
| 周六 | 休息 |
| 周日 | 休息 |

## 三、动作库 & 执行细节

### 🟦 推胸日（Push）

| 动作 | 组数 | 次数 | 备注 |
|------|------|------|------|
| 杠铃平板卧推 | 4 | 8～12 | 核心收紧，肩胛骨锁定 |
| 哑铃上斜卧推 | 4 | 10～12 | 上胸刺激，肘部 45° |
| 绳索夹胸 | 3 | 12～15 | 收尾动作，全程控制 |
| 哑铃侧平举 | 4 | 12～15 | 不要借力，小重量高质量 |
| 绳索下压（三头） | 4 | 12～15 | 锁定肘关节，只动小臂 |

### 🟩 拉背日（Pull）

| 动作        | 组数  | 次数    | 备注          |
| --------- | --- | ----- | ----------- |
| 引体向上（或辅助） | 4   | 力竭    | 宽握，拉到锁骨     |
| 杠铃划船      | 4   | 8～12  | 背保持挺直，肘贴近身体 |
| 高位下拉      | 4   | 10～12 | 感受背阔肌收缩     |
| 坐姿划船      | 3   | 12～15 | 挤压肩胛骨       |
| 哑铃弯举（二头）  | 4   | 10～12 | 肘部固定，控制离心   |

### 🟨 腿日（Legs）

| 动作 | 组数 | 次数 | 备注 |
|------|------|------|------|
| 杠铃深蹲 | 4 | 8～12 | 核心锁死，膝盖对准脚尖 |
| 罗马尼亚硬拉 | 4 | 10～12 | 臀部后推，感受腘绳肌 |
| 腿举机 | 4 | 12～15 | 全程控制，不锁死膝盖 |
| 哑铃箭步蹲 | 3 | 每腿10 | 核心稳定，重心居中 |
| 站姿提踵 | 4 | 15～20 | 小腿收尾 |

## 四、有氧安排

### 最佳搭配策略

```
力量训练后 → 30 分钟有氧（燃脂效率最高）

空腹有氧 → 非必须，效果差异不大，看个人习惯
```

### 有氧类型

| 类型 | 时长 | 频率 | 效果 |
|------|------|------|------|
| 快走 / 坡度走 | 30～45min | 每天 | 低门槛，好坚持 |
| 慢跑（心率 Zone2） | 30～40min | 3～5次/周 | 燃脂效率高 |
| HIIT（间歇跑/单车） | 15～20min | 2～3次/周 | 保留肌肉，后燃效应 |
| 爬楼梯 | 20～30min | 3次/周 | 翘臀+燃脂 |

> 💡 **坡度走是最推荐的减脂有氧**
> 设定：坡度 10～12，速度 4～5km/h，心率保持在 130～140

## 五、饮食计划

### 三大营养素分配

**推荐比例：蛋白质 35% / 碳水 40% / 脂肪 25%**

以 60kg 女性为例（减脂期）：

| 营养素 | 每日摄入 | 食物来源 |
|--------|---------|---------|
| 蛋白质 | 100～120g | 鸡胸、鱼肉、鸡蛋、蛋白粉、豆腐 |
| 碳水 | 150～180g | 燕麦、红薯、糙米、全麦面包 |
| 脂肪 | 35～45g | 橄榄油、坚果、牛油果、蛋黄 |

### 一日饮食模板

```
早餐 07:30
  燕麦 50g + 鸡蛋 2个 + 蓝莓一把 + 黑咖啡

加餐 10:00
  希腊酸奶 150g + 坚果 10g

午餐 12:30
  鸡胸肉 150g + 糙米饭 150g + 西兰花不限量

训练前 16:00
  香蕉 1根 + 黑咖啡（可选）

训练后 18:30
  蛋白粉 1勺 + 米饭 100g + 蔬菜不限量

晚餐 20:00
  三文鱼/豆腐 150g + 沙拉（橄榄油醋汁）
```

### 碳水循环（进阶）

| 训练日（高碳） | 休息日（低碳） |
|---------------|--------------|
| 碳水 2.5g/kg | 碳水 1g/kg |
| 蛋白质 2g/kg | 蛋白质 2g/kg |
| 脂肪 0.8g/kg | 脂肪 1g/kg |

## 六、恢复与睡眠

### 睡眠 = 减脂的加速器

- 睡眠不足 → 皮质醇升高 → 腹部脂肪堆积
- 每天睡足 **7～8 小时**，效果翻倍
- 睡前 1 小时远离手机蓝光

### 训练恢复

- 同一肌群至少休息 **48 小时**
- 每周至少 1 个 **完全休息日**
- 拉伸 / 泡沫轴放松 → 减少肌肉酸痛
- 喝够水：每天 **体重大概（kg）x 35ml**

## 七、减脂避坑指南

| ❌ 错误做法 | ✅ 正确做法 |
|-----------|-----------|
| 每天只吃 800kcal | 制造 300～500kcal 缺口 |
| 只做有氧不做力量 | 力量 + 有氧结合 |
| 完全不碰碳水 | 吃对碳水更有利于减脂 |
| 每天称体重焦虑 | 每周称一次 + 拍照对比 |
| 训练不记录 | 记录重量/组数/次数/饮食 |
| 迷信局部减脂 | 减脂是全身性的，腹肌是厨房练出来的 |

## 八、阶段性计划示例

### 第一阶段：适应期（第 1～4 周）

目标：养成运动习惯，学习动作模式

```
每周 4 练（上下肢分化）
每次 45 分钟力量 + 20 分钟坡度走
饮食先戒掉奶茶、零食、外卖即可
```

### 第二阶段：燃脂期（第 5～8 周）

目标：稳定减脂 2～4kg

```
每周 5 练（推拉腿分化）
每次 60 分钟力量 + 30 分钟有氧
开始记录饮食，保证蛋白质摄入
```

### 第三阶段：精雕期（第 9～12 周）

目标：体脂率降低 3～5%

```
每周 6 练
强度提升（渐进超负荷）
加入 HIIT，碳水循环开始
每周拍照对比，调整计划
```

## 十、最重要的心态

> **减脂不是 21 天的事**
> 是一种生活方式的转变
> **慢就是快，坚持就是胜利**

- 不要追求完美，偶尔吃一顿不会毁了你
- 不要和别人比，只和昨天的自己比
- 平台期是正常的，调整计划继续前进
- 肌肉比体重更重要，关注镜子而不是秤
