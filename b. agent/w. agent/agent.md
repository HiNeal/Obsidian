## oyagent-mcp

```text
												  +-----------------------+
												  |                       |
												  |                       |
												  |          User         |
												  |                       |
												  |                       |
												  +-----------------------+
														   |    |
														   |    |            +------------------------+
														   |    |            |                        |
														   |    |            |  +-----------------+   |
														   |    |            |  |   User Prompt   |   |
														   |    |            |  +-----------------+   |
														   |    |            |                        |
														1. |    | 8.         |  +-----------------+   |
														   |    |            |  |  System Prompt  |   |
														   |    |            |  +-----------------+   |
														   |    |            |                        |
														   |    |            |  +------------------+  |
														   |    |            |  | Function Calling |  |
														   |    |            |  +------------------+  |
														   |    |            |                        |
														   |    |            +------------------------+
														   v    |
+-----------------------+             2.           +-----------------------+           3. / 4.          +-----------------------+
|                       | <----------------------> |                       | <------------------------> |                       |
|       MCP Server      |                          |        Agent          |                            |         LLM           |
|         (Tool)        |                          |     (MCP Client)      |                            |         LLM           |
|                       | <----------------------> |                       | <------------------------> |                       |
+-----------------------+             5.           +-----------------------+           6. / 7.          +-----------------------+

1.User提出问题Agent会将问题封装为User Prompt;
2.Agent通过MCP协议获取所有Tool的信息并将这些信息转化成为System Prompt或Function Calling;
3.Agent会将User Prompt / System Prompt / Funciton Calling 一起打包发送给大语言模型;
4.大语言模型通过普通回复或者Function Calling格式产生一个调用这个Tool的请求;
5.Agent收到请求后通过MCP协议调用MCP Server的工具工具执行任务后将内容返还给Agent;
6.Agent将工具的答复转发给大语言模型;
7.大语言模型根据工具的答复和自己的头脑风暴将最终答案给Agent;
8.Agent最终将答案返回给User

```
