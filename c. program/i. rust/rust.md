## 常量

```rust
// 定义常量
const $DATA: $type = $value;

/*
 * - 常量编译期不会自动进行类型推断, 因此必须显示指定数据类型,且常量的初始化表达式必须是编译常量;
 * - 常量的作用域为全局作用域
 *
 */

```

## 变量 - 不可变

```rust
// 变量绑定(不可变)
let $data = $value;

/*
 * - 不可变变量绑定的值不能修改,但是可以通过let创建新同名变量进而重新绑定新的类型和值(遮蔽机制)
 *
 *  let data = 100;
 *  let data = "hello world";
 */

```

## 变量 - 可变

```rust
// 变量绑定(可变)
let mut $data = $value;

```

## rust - 命名规范

```rust
Rust 命名规范:

- 变量/函数/方法采用下划线命名
- 枚举/结构体采用驼峰命名法
```
