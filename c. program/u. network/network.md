## oynetwork-tcp

```text
+------------+                      +------------+
               |   Client   |                      |   Server   |
               +------------+                      +------------+
                     |                                    |
                     |                                    |
                     |         SYN = 1 & seq = J          |
         SYN_SENT    | -------------------------------->  |
                     |                                    |
                     |                                    |
                     |                                    |
                     |         SYN = 1 & ACK = 1          |
                     | <--------------+-----------------  | SYN_RECV
                     |     ack = J + 1 & seq = K          |
                     |                                    |
                     |                                    |
                     |                                    |
                     |         ACK = 1 & ack = K + 1      |
      ESTABLISHED    | -------------------------------->  |
                     |                                    |
                     |                                    |

  /**
   * TCP三次握手:
   *
   * - 第一次握手：客户端向服务器发送请求数据包在发送后进入SYN_SENT状态;
   *             数据包内容包含标志位SYN值为1和随机序列号seq假设随机序列号seq值为J;
   * - 第二次握手：服务器接收到之后会向客户端发送确认数据包在发送后进入SYN_RECV状态;
   *             数据包内容包含标志位SYN和ACK值都为1确认序列号ack值为J+1和随机序列号seq假设随机序列号seq值为K;
   * - 第三次握手：客户端接收到之后向服务器发送确认数据包在发送后进入ESTABLISHED状态
   *             数据包内容包含标志位ACK值为1和确认序列号ack值为K+1;当服务器接收到确认数据包后也进入ESTABLISHED状态到此TCP握手结束;
   */

```

## oynetwork-http

```text
Host            // 服务器的域名、端口号
Date            // 发送该消息的日期和时间表示浏览器所访问的前一个页面
Range           // 仅请求某个实体的一部分。字节偏移以开始
Origin          // 发起一个针对跨域资源共享的请求
Cookie          // 之前由服务器通过Set-Cookie发送的Cookie
Referer         // 正是前一个页面的某个链接将浏览器带到了当前这个页面
User-Agent      // 浏览器的身份标识字符串
Connection      // 该浏览器想要优先使用的连接类型
Content-Type    // 请求体的类型
Content-Length  //请求体的长度（字节为单位）
Cache-Control   // 用来指定在这次的请求/响应链中的所有缓存机制都必须遵守的指令

```

## oynetwork-cookie

```text
+---------------+                                 +---------------+
          |    Cookie     | ------------------------------> |    Session    |
          |  (session ID) | ------------------------------> |    Session    |
          +---------------+                                 +---------------+
              (客户端)                                            (服务端)

  /*
   * Cookie和Session区别:
   *
   * - Cookie是存储在客户端磁盘的数据每当访问同一网站时会被发送回服务器;
   * - Session是存储在服务端的信息当用户在一个会话中访问网站服务器会创建一个session并生成唯一的session ID;
   * - session ID会被存储在客户端的cookie中一并发送回服务器;
   */

```
