## 进程和线程的区别

- 进程是操作系统进行资源分配和调度的一个独立单位,而线程作为进程的一个实体是CPU分派和调度的基本单位;
  从操作系统发展史的角度看经历了从之前的进程到用户线程,到轻进程再到内核线程作为基本调度单元;
- 进程拥有自己独立的堆栈且都不共享,且进程间切换有较大的开销;线程拥有自己独立的栈共享的堆,相比进程切换开销较小;
  栈空间是绝对线程安全的,而堆空间是线程不安全的;

## app在操作系统中的内存划分

```text
代码段: 用于存放编译后的代码;
数据段: 用于存放字符串常量 & 静态变量 & 全局变量等;
堆: 用于存放对象本身和block的拷贝等,内存管理由开发者负责,分配的内存地址越来越大;
栈: 用于存放对象指针和局部变量等,内存管理由操作系统负责,分配的内存地址越来越小;
内核区: 用于存放操作系统内核相关的东西;

```

## 编译过程

```text
- 预处理: 处理define & include & 注释 & 条件预编译指令;
- 编译: 进行词法分析、语法分析和语义分析,最后生成汇编文件;
        词法分析负责将代码分割成关键字、标识符和字面量等记号;
        语法分析负责生成语法树;语义分析负责检查语义是否合法包括类型匹配和类型转换;
- 汇编: 将汇编指令翻译为机器指令最后生成目标文件;
- 链接: 将所有目标文件和静态库文件合并生成可执行文件(a.out);

  gcc -E main.c -o main.i             // 预处理
  gcc -S main.i -o main.s             // 编译
  gcc -c main.s -o main.o             // 汇编

```

## 断点的原理

- 断点底层实现是在指令位置上插入一个中断指令从而中断程序的运行,并将控制权转交给调试器内核;
  调试器会在断点处查看当前线程的状态,包括寄存器、内存和堆栈;

## backtrace的实现的原理

- 函数调用的本质是压栈的过程,backtree底层实现是从寄存器获取到当前线程的栈帧结构和上一个函数的返回地址,
  然后递归形成堆栈地址信息,最后通过符号表将堆栈地址信息转换为函数名和行号;

## mmap的概念和在文件读取中的使用

- mmap是一种文件映射到内存的机制,使得进程可以通过指针直接访问映射区域上的数据,减少了IO操作,提高了文件的访问效率;

- 进程在虚拟内存中创建出一块映射区域,然后调用操作系统内核函数mmap实现文件物理地址和虚拟内存地址的一一对应;
  最后开始访问映射区域引发缺页异常,从而实现文件到内存的拷贝;
