```css
//  通过给父盒子添加flex属性来控制子盒的位置和排排列方式

/**  
 * display                          设置布局方式
 * 
 * display: flex                    设置为flexbox布局方式
 *
 * -------------------------------------------------------
 * flex-direction                   设置指定主轴(子元素跟着主轴排列)
 * 
 * flex-direction: row              设置x轴为主轴(默认)
 * flex-direction: column           设置y轴为主轴
 * -------------------------------------------------------
 *
 * justify-content                   设置主轴上子元素排列方式
 *
 * justify-content: flex-start       从主轴开始处排列
 * justify-content: flex-center      沿主轴居中对齐
 * justify-content: flex-end         从主轴结束处排列
 * justify-content: space-around     平分主轴剩余空间(margin平分)
 * justify-content: space-between    贴边主轴再平分剩余空间
 *
 * --------------------------------------------------------
 *
 * align-items                        设置侧轴上子元素的排列方式(单行)
 *
 * align-items: flex-start            从侧轴开始处排列
 * align-items: flex-end              从侧轴结束处排列
 * align-items: center                沿侧轴居中对齐
 * align-items: stretch               设置子项元素高度平分父元素高度
 *
 * --------------------------------------------------------
 *
 * align-content                      设置侧轴上子元素排列方式(多行)
 * 
 * align-content: flex-start          从侧轴开始处排列
 * align-content: flex-end            从侧轴结束处排列
 * align-content: center              沿侧轴居中对齐
 * align-content: space-around        平分侧轴剩余空间
 * align-content: space-between       贴边侧轴再平分剩余空间
 * align-content: stretch             设置子项元素高度平分父元素高度
 * 
 * 
 * --------------------------------------------------------
 *
 * flex-warp                          设置子元素是否换行
 *
 * flex-warp: nowarp                  设置不换行(默认)  
 * flex-warp: warp                    设置换行
 *
 * -------------------------------------------------------- 
 *
 *
 */

```
