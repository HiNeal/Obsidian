# 连音

## 辅元连音

辅音结尾 + 元音开头 → 词尾辅音顺势滑入后词元音拼读, 不停顿、不额外添加元音。

词尾 t 连到下一个元音时, 英音读清楚的送气 `/t/`(get out、what about you), 美音会读成像 d 的闪音; 想听起来像英音, 就把 t 读清楚。

看读音, 不看拼写：once 拼写以 e 结尾, 读音以 /s/ 结尾, 照样连读(once in a while)。词尾暗音 L 遇元音时变回清晰 L 连过去(he will always)。连读不是每次都必须, 自然顺口时再连。

## 卷舌连音

词尾拼写含字母 r + 后词元音开头 → 激活发音 /r/ 充当跨词桥梁(Linking r)。英音词尾 r 本身不发音, 遇后接元音时复活; 美音则为元音卷舌自然连拼。

# 加音

前词元音结尾 + 后词元音开头 → 插入过渡滑音(/r/, /w/, /j/), 避免元音相撞或生硬停顿。

## 卷舌加音

单词末尾拼写**无字母 r**, 但以非闭口元音(`/ə/`、`/ɑː/`、`/ɔː/`)结尾, 英音后接元音时自然插入 `/r/` 滑音(Intrusive r)。

卷舌加音是可选的：有人认为它不规范, 但英格兰南部的母语者普遍这样说; 自己可以不用, 但要听得懂。

| :--- | :--- |
| media event | /ˈmiːdiər ɪˈvent/(卷舌加音：词尾元音 /ə/ 遇元音自然滑出 /r/) |
| Australia and England | /ɒˈstreɪliər ənd ˈɪŋɡlənd/(卷舌加音：词尾元音 /ə/ 遇元音自然滑出 /r/) |

| /ɑ:/ + 加/r/ + 元音 | 解释 |
| :--- | :--- |
| grandma and grandpa | /ˈɡrænmɑːr ənd ˈɡrænpɑː/(卷舌加音：词尾元音 /ɑː/ 遇元音自然滑出 /r/) |

| /ɔ:/ + 加/r/ + 元音 | 解释 |

# 弱读

弱读(Weak Form)指非重读虚词将饱满元音弱化为中央元音 `/ə/`(个别弱化为 `/ɪ/`), 以维持句子的重音等时节奏。

## 单词弱读

单词内部这三种情况读 `/ə/`：
- **词尾 -er 等带 r 的拼写**：英音不卷舌, 只读 `/ə/`(better、teacher);
- **非重读音节**：重音以外的元音弱化(police、sofa、about);
- **任何元音字母**：a、e、i、o、u 甚至 y 都可能读成 `/ə/`(again、problem、president、bottom、album、syringe)。

重读音节音更高、更长、更用力; 弱读音节只负责把单词「带过」, 读得快而放松(如 about：力气都在 bout 上, 前面的 a 只是一个 `/ə/`)。

## 短语弱读

非重读位置的单音节**虚词**(介词、冠词、连词、代词、助动词、情态动词)：

功能词多数有强读和弱读两种形式：需要强调时用强读, 正常说话用弱读(元音弱化为 `/ə/`)。the 在辅音前读 `/ðə/`, 在元音前读 `/ðiː/` 并与后词连读。

虚词在三种情况下要读强式：在句末(Yes, I want to.／Where are you from?); 需要强调或纠正时(I said I *can* do it); to 后面紧接元音时读 /tuː/, 并用 /w/ 连过去(to add、to eat)。

# 同化

相邻音素为了发音顺畅省力, 在发音部位或发音方式上互相靠拢同化(求同)。

## 顺行同化(后音改变)

前音的特征（声带振动或发音部位）顺延并强制后音做出改变。

### 顺行浊化

前音为浊音（浊辅音或元音, 声带持续振动）, 声带振动顺延导致紧随其后的清辅音被同化为浊音。

1. **词内语法变形（固化规则）**：
   - 浊音后接复数/三单 `-s` ➔ 顺行浊化读 `/z/`（如 `dogs` `/dɒɡz/`、`reads` `/riːdz/`）;
   - 浊音后接过去式 `-ed` ➔ 顺行浊化读 `/d/`（如 `cleaned` `/kliːnd/`、`played` `/pleɪd/`）。
2. **跨词连读语流（听力高频）**：
   - 前词词尾为浊辅音（尤其是 `/d/`、`/n/`、`/l/`）, 后词词首为清擦音 `/s/` 时, 声带振动顺延使 `/s/` 浊化为 `/z/`。

| 浊辅音/元音 + 清音 → 顺行浊化 | 解释 |
| :--- | :--- |
| dogs | /dɒɡz/(词内顺行浊化：浊爆破音 `/ɡ/` 使复数 s 读 `/z/`) |
| cleaned | /kliːnd/(词内顺行浊化：浊鼻音 `/n/` 使过去式 -ed 读 `/d/`) |
| played | /pleɪd/(词内顺行浊化：双元音 `/eɪ/` 是浊音, 使 -ed 读 `/d/`) |
| wild settings | /ˈwaɪld ˈsetɪŋz/ → [ˈwaɪld ˈzetɪŋz](跨词顺行浊化：词尾浊音 `/d/` 声带振动顺延, 后词 `/s/` 浊化为 `/z/`, 听觉呈现 "wild zting") |
| read so much | /riːd səʊ mʌtʃ/ → [riːd zəʊ mʌtʃ](跨词顺行浊化：词尾浊音 `/d/` 顺延使 so 的 `/s/` 浊化为 `/z/`) |
| in some ways | /ɪn sʌm weɪz/ → [ɪn zʌm weɪz](跨词顺行浊化：齿龈浊鼻音 `/n/` 顺延使 some 的 `/s/` 浊化为 `/z/`) |

### 顺行清化

前音为清辅音（声带不振动）, 导致后音同样保持清辅音。

- 清辅音后接复数/三单 `-s` ➔ 顺行读清音 `/s/`（如 `books` `/bʊks/`、`cats` `/kæts/`）;
- 清辅音后接过去式 `-ed` ➔ 顺行读清音 `/t/`（如 `laughed` `/lɑːft/`、`hoped` `/həʊpt/`、`watched` `/wɒtʃt/`）。

| 清辅音 + 辅音 → 顺行清化 | 解释 |
| :--- | :--- |
| books | /bʊks/(顺行清化：清爆破音 `/k/` 使复数 s 保持清擦音 `/s/`) |
| laughed | /lɑːft/(顺行清化：清擦音 `/f/` 使 -ed 保持清爆破音 `/t/`) |
| watched | /wɒtʃt/(顺行清化：清破擦音 `/tʃ/` 使 -ed 保持清爆破音 `/t/`) |

| :--- | :--- |

## 逆行同化(前音改变)

前音受后音影响而发生性质或发音部位改变(如失去爆破、浊音清化、双唇化等)。注意：of 本来的结尾音是 `/v/`(常被误以为是 `/f/`), 遇到清辅音才同化为 `/f/`。

## 相互同化(全部改变)

前后音互相影响, 产生质变或融合：

### 音素融合

齿龈音 `/t/`、`/d/`、`/s/`、`/z/` 与硬腭半元音 `/j/`（或后齿龈音 `/r/`）相遇, 融合成新的腭龈擦音或破擦音：

单词内部的融合(Tuesday、student、education)是现代 RP 的常见读法, 传统 RP 读 /tj/、/dj/, 两种都对。

t + you 有三种读法, 都是英音：融合成 `/tʃ/`(nice to meet you)、读出 /t/ 再接 /j/、或者喉塞; 按说话的正式程度和语速选择。

| /t/ + /j/ → /tʃ/ | 解释 |
| :--- | :--- |
| Nice to meet you | /ˈnaɪs tə ˈmiːtʃuː/(音素融合：清爆破音 `/t/` 遇半元音 `/j/` 融合成清破擦音 `/tʃ/`) |
| can't you come to the party | /kɑːnt juː/ → [ˈkɑːntʃuː](音素融合：can't 词尾 `/t/` 遇 `/j/` 融合成 `/tʃ/`) |
| you're from England, aren't you | /ɑːnt juː/ → [ˈɑːntʃuː](音素融合：反义疑问句 aren't you 中 `/t/` 遇 `/j/` 融合成 `/tʃ/`) |
| where did you get your top | /ɡet jə/ → [ˈɡetʃə](音素融合：get 词尾 `/t/` 遇 your 的 `/j/` 融合成 `/tʃ/`; did you 同时融合成 `/dʒ/`) |

# 省音

语流中为了维持重音等时节奏与发音经济性, 自然省略最耗力且不影响辨义的音素(如夹心爆破音 `/t/`、`/d/`、非重读弱擦音 `/h/`、`/v/`、弱元音 `/ə/` 等)。

## 单词间省音

### 喉塞吞音

英式口语常把词尾的 t 换成喉塞音, 尤其是 it、bit、but 这类功能词; 这是可选的, 读出 t 也正确。两个元音之间的 t 也可以用喉塞(whatever、water), 但难度较高, 先学会把 t 读清楚。喉塞不是把 t 删掉, 而是喉咙收紧、在 t 的位置把声音截断。

# 注意事项

## /t/ 发音

英音一定要把 /t/ 读出来, 尤其是两个元音之间的 t(city、water)：舌尖抵住齿龈、轻轻释放, 不要像美音那样读成 d, 也不要用力喷气。

## /θ/ 与 /ð/

/θ/ /ð/ 舌尖必须放在上下齿之间, 不能读成 /s/ /t/ /d/ /f/(think 不读 sink、tink 或 fink, this 不读 dis)。说得很快时舌尖来不及伸出来, 可以只在上齿尖背面轻点一下带过。舌尖只是轻放在上下齿之间, 不要咬住。词尾的浊辅音会稍微清化(breathe 的 /ð/ 声音变弱), 但仍要带一点声带振动, 否则就成了 breath。

| 单词 | 解释 |
| :--- | :--- |
| thank | /θæŋk/：清音 /θ/, 舌尖在齿间, 只送气不发声 |
| thunder | /ˈθʌndə/：词首清音 /θ/, 不读成 sunder 或 tunder |
| birthday | /ˈbɜːθdeɪ/：词中 /θ/ 后紧接 /d/, 舌尖要快速从齿间收回 |
| something | /ˈsʌmθɪŋ/：词中清音 /θ/ |
| breath | /breθ/：词尾清音 /θ/(名词) |
| breathe | /briːð/：词尾浊音 /ð/(动词), 声带轻微振动; 元音是长 /iː/ |
| others | /ˈʌðəz/：浊音 /ð/, 舌尖在齿间; 读成 /d/ 就成了 udders(奶牛乳房) |
| father | /ˈfɑːðə/：词中浊音 /ð/ |
| weather | /ˈweðə/：词中浊音 /ð/ |
| together | /təˈɡeðə/：词中浊音 /ð/ |
| the brother from another mother | 练习句：连续几个浊音 /ð/, 说快时舌尖可只轻点上齿 |

## 暗音 L

暗音 L 是偷懒的 L：舌头一直抬在上面不落下, 嘴唇略圆、口型小, 听起来像在发一个元音。词尾的 L 后面紧跟元音开头的词时, 要变回清晰 L 连到下一个词(he will always、can you smell it)。

| :--- | :--- |
| tall | /tɔːɫ/：词尾 L 在元音后, 舌头抬起不落下 |
| always | /ˈɔːɫweɪz/：L 在辅音前, 读暗音 |
| tinsel | /ˈtɪnsəɫ/：词尾 -sel 弱读, L 读暗音 |
| bauble | /ˈbɔːbəɫ/：词尾 -ble 的 L 读暗音 |
| carols | /ˈkærəɫz/：L 在辅音 /z/ 前, 读暗音 |
| film | /fɪɫm/：L 在辅音前, 读暗音, 不要加元音读成 filum |
| elf | /eɫf/：L 在辅音前, 读暗音 |
| help | /heɫp/：L 在辅音 /p/ 前读暗音, 舌尖抬着不弹下来, 听起来像 /ʊ/; h 要轻, 不要在喉咙里用力 |

## 辅音连缀

## 绕口令

绕口令把相近的音编进一句话, 用来训练口腔肌肉的动作切换：每天念一两个, 先说对再加速, 越念越快; 也可以针对自己容易混的音自己编。

| 例句                                                                                 | 解释                                                     |
| :--------------------------------------------------------------------------------- | :----------------------------------------------------- |
| She sells seashells by the seashore                                                | 绕口令：练习 /s/ 与 /ʃ/ 的快速切换; 自己编的绕口令比网上找的更容易记住               |
| Red lorry, yellow lorry                                                            | 练习 /r/ 与 /l/ 的切换：/l/ 舌尖碰上齿龈再落下, /r/ 舌尖不碰                |
| Red leather, yellow leather                                                        | 在 /r/、/l/ 之外再加 /ð/：舌尖放到上下齿之间                           |
| How can a clam cram in a clean cream can                                           | 练习 /kl/ 与 /kr/ 连缀; clean、cream 的 /iː/ 嘴角要笑开             |
| The thirty-three thieves thought that they thrilled the throne throughout Thursday | 练习 /θ/ 与 /ð/：每个 th 都要把舌尖放到齿间, 不要读成 dirty tree 或 /d/、/z/ |
| I slit a sheet, a sheet I slit, upon the slitted sheet I sit                       | 练习 /s/ 与 /ʃ/、/ɪ/ 与 /iː/：slit 舌尖碰上齿龈再落下发 /l/            |
| Shut up the shutters and sit in the shop                                           | 练习 /ʃ/ 与 /s/ 的切换                                       |
