# 基础知识

## 发音步骤

![[口腔部位.png|472]]

人类发音实际上是一个连贯的过程, 可以分为四个步骤：

1. **肺部气流**：肺部产生并挤压气流;
2. **声带抉择**：气流来到喉咙的声带时, 声带能决定是否振动(开关);
3. **调形或受阻**：元音通过嘴唇、舌头、下巴调形气流通道的形状, 辅音通过制造阻碍;
4. **气流的释放**：气流离开人体, 一个音的发音过程完成;

核心主张：发音最重要的是**肌肉动作**而非认知记忆, 它更接近学跳舞(身体活动), 而不是学语法词汇(认知活动)

## 清音 vs 浊音

| 特征       | 浊音（Voiced） | 清音（Voiceless） |
| -------- | ---------- | ------------- |
| **声带振动** | 声带会振动      | 声带不振动         |
| **声音来源** | 声带的周期性振动   | 气流通过狭窄处摩擦     |
| **声音特点** | 像唱歌有明显音调   | 像吹风只有气息声      |

## 元音 vs 辅音

| 特征       | 元音                                | 辅音                                             |
| -------- | --------------------------------- | ---------------------------------------------- |
| **音源**   | 由声带振动产生, 因此元音都是浊音                 | 气流摩擦产生(清音) / 声带振动产生(浊音)                        |
| **例音**   | /i:/, /ɪ/, /ʊ/, /u:/%%  %%        | /p/, /b/, /t/, /d/, /k/, /g/                   |
| **气流阻碍** | 气流通过口腔不受阻碍                        | 气流在部分或全部时间受到阻碍                                 |
| **区分依据** | 靠口腔的形状和容积（由舌头、嘴唇、下巴决定）            | 靠阻碍：哪两个面合拢或接近, 以及在那里做什么                        |
| **参与器官** | 靠舌头、嘴唇、下巴三者改变开度, 但不与任何部位接触, 嘴唇不闭合 | 需要两个接触面合拢或接近（上唇、下唇、上齿、舌尖、舌面、舌后、齿龈、龈后、硬腭、软腭、声门） |

**核心认知**：元音只定义**音色**（口型共鸣）, 声带才决定**音高/声调**。只要舌位唇形到位, 即使声调不同, **元音就绝对标准**。

## 四个肌肉按钮

发音需要支配的肌肉只有四组, 即四个**肌肉按钮**, 如果能随意操作这四个, 就能走出母语的音位范围

| 器官/按钮 | 动作方向 | 决定特征 | 自查动作（用手直接感知肌肉） |
| --- | --- | --- | --- |
| **声带** | 开 ↔ 关 | 清浊（元音恒开, 辅音起区分作用） | 手放喉部, /s/ ↔ /z/ 来回切换, 感受振动的"开关" |
| **舌头** | 前 ↔ 后 | 舌位前后 | 摆好 /iː/ 口型不出声, 指尖顶住舌尖滑向 /uː/, 感受舌头后退约半指 |
| **嘴唇** | 展平后收 ↔ 圆起前突 | 圆唇度 | 捏住嘴角在 /iː/ ↔ /uː/ 之间慢滑, 感受"展平后收"变"圆起前推" |
| **下巴** | 上 ↔ 下 | 开口度（舌位高低随之升降） | 捏住下巴在 /e/ → /æ/ 之间滑, 感受下巴下沉、口腔变大、舌头随之下降 |

嘴唇和舌头在英语里是反向联动：舌头前 → 嘴唇展平后收; 舌头后 → 嘴唇圆起前突。

## 单元音


 **元音是互相定义的**：一个元音的边界就是下一个元音的起点, 所以不存在"先学会几个再学下几个"的顺序。分成高／中／低三张表只是为了整理, 练的时候应该把 12 个铺开、成组对比, 尤其是**表上紧挨着的那几个**——最容易混的永远是邻居。

| 练法       | 做法                                              |
| -------- | ----------------------------------------------- |
| **滑动**   | 在两个相邻元音之间来回慢滑。差别在滑动过程中比静止对比时明显得多, 而且能顺带确认是哪个按钮在动 |
| **卸力对比** | 同一个位置"用力／不用力"来回切换。肌肉张力对元音音质的影响极大——**动作很小, 差别很大** |
### 高元音

**下巴合到最拢**, 口腔空间最小, 舌头随之抬到最高。

| 音标   | 发音技巧                                               |
| ---- | -------------------------------------------------- |
| /iː/ | 嘴唇角两侧展开并后收, 舌头向前且高, 靠近齿龈但不接触, 舌头后面和上牙后齿是贴着的        |
| /ɪ/  | 在 /iː/ → /uː/ 的滑动中停住; 比 /iː/ 短、更放松, 嘴唇和舌头的肌肉张力减弱。  |
| /ʊ/  | 在 /uː/ → /iː/ 的滑动中停住; 比 /uː/ 短、更放松, 嘴唇仍趋圆, 但不推到最满。 |
| /uː/ | 嘴唇变窄、圆起并向前推, 舌头向后; 从 /iː/ 慢滑到这里, 用手可感觉 嘴唇前推、舌头后退。  |

### 中元音

下巴张开到中间程度。

| 音标       | 发音技巧                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| /e/      | 舌头在前, 舌尖轻触下门牙背面; 舌前部略抬, 嘴角有一点向两侧的张力                                                       |
| /ə/      | **“小傻瓜音”**：和 /ɜː/ 是同一个中央放松位置, 但做得很短、很小; 舌头在中间, 一切保持中性放松                                   |
| ==/ɜː/== | **“大傻瓜音”**：脸、嘴唇、下巴、舌头全部卸掉肌肉张力, 像无表情的 无表情的“傻瓜脸”; 接上气和声并拖长                                  |
| /ɔː/     | 嘴唇圆起前推, 舌头向后; 相对 /uː/ 下巴更打开, 口腔里腾出更大的共鸣空间<br  >可从 邻居/ɜː/ 滑过来找, 一路感受嘴唇前推、舌头后退、肌肉张力从"松"变"紧" |


### 低元音

**下巴张到最开**, 舌头随之降至最低。

| 音标   | 发音技巧                                                 |
| ---- | ---------------------------------------------------- |
| /æ/  | 下巴相当打开, 嘴唇仍向两侧展平, 舌头抵住下齿龈; 可从 /e/ 往下滑, 感觉下巴下降        |
| /ʌ/  | 下巴打开, 嘴唇自然打开但不展开, 舌头大致躺在口腔底部、完全不成形, 很短               |
| /ɑː/ | **“按摩音／听八卦音”**：口腔打开, 嘴唇不圆, 舌头低, 声音从更深、更大的口腔空间出来; 拖长。 |
| /ɒ/  | 想象嘴里含着一整个橘子：里面空间大、舌头靠后; 嘴唇向前并趋向圆小, 像要把橘子藏住; 短音。      |



## 双元音


规则：单元音练扎实之后, 8 个双元音**不需要另外学**, 只需要分别确认起点音和终点音, 各自能单独发准, 然后从第一个音滑向第二个音, 前重后轻加速到正常语速, 连贯不断开 8 个双元音按收尾音分成三组

| 收尾          | 音标                           | 滑动方向                                        | 滑的时候哪个按钮在动                                                  |
| ----------- | ---------------------------- | ------------------------------------------- | ----------------------------------------------------------- |
| <br><br>/ə/ | /ɪə/<br><br>/ʊə/<br><br>/eə/ | /ɪ/ → /ə/<br><br>/ʊ/ → /ə/<br><br>/e/ → /ə/ | 舌头由前移向中央, 同时卸掉张力<br><br>嘴唇由圆变松, 舌头由后移向中央<br><br>舌前部放下, 张力卸掉 |
| <br><br>/ɪ/ | /eɪ/<br><br>/ɔɪ/<br><br>/aɪ/ | /e/ → /ɪ/<br><br>/ɔ/ → /ɪ/<br><br>/æ/ → /ɪ/ | 下巴合拢, 舌头随之抬起<br><br>嘴唇由圆变平、舌头由后到前, **跨度最大**<br><br>下巴由开合拢   |
| <br>/ʊ/     | /əʊ/<br><br>/aʊ/             | /ə/ → /ʊ/<br><br>/æ/ → /ʊ/                  | 嘴唇由松变圆前推<br><br>下巴由开合拢, 同时嘴唇圆起                              |

两个要点：

| 要点             | 说明                                                 |
| -------------- | -------------------------------------------------- |
| **真实语速下到不了终点** | 双元音在实际说话中通常滑不完就停了; 但练习时要先能**刻意滑到底**, 才谈得上控制滑多少     |
| **双元音是看得见的**   | 它是一段可见的肌肉位移, 可以只看口型、不听声音就认出是哪一个——这是"发音是身体动作"最直观的证据 |

## 辅音

相比元音通过下巴, 嘴唇和舌位, 辅音靠**制造阻碍**, 位置摸得着、定得准。分析任何辅音只需看两点：

| 问题                | 例子                                                                          |
| ----------------- | --------------------------------------------------------------------------- |
| <br><br>哪两个面在挡气流？ | /p/ /b/ /m/ = 上唇 + 下唇<br><br>/f/ /v/ = 上齿 + 下唇<br><br>/t/ /d/ /n/ = 舌尖 + 齿龈 |
| <br><br>挡完之后做什么？  | 爆破音: 完全堵住再放开<br><br>擦音: 留条缝擦过去<br><br>鼻音: 堵住让气走鼻子                           |

|     |     |     |     |     |     |     |     |
| --- | --- | --- | --- | --- | --- | --- | --- |
| p   | b   | t   | d   | tʃ  | dʒ  | k   | g   |
| f   | v   | θ   | ð   | s   | z   | ʃ   | ʒ   |
| m   | n   | ŋ   | h   | l   | r   | w   | j   |

### 爆破音

爆破音都有**两个阶段**：先封闭蓄气, 再突然释放, 清浊成对出现

| 清音   | 浊音   | 两个接触面   | 发音技巧                                                                        |
| ---- | ---- | ------- | --------------------------------------------------------------------------- |
| /p/  | /b/  | 上唇 + 下唇 | 双唇闭合再释放<br><br>/p/的气在双唇后面累积, 释放时纸片会动<br><br>/b/同一双唇位置, 但气主要在下方为声带供能, 纸片几乎不动 |
| /t/  | /d/  | 齿龈 + 舌尖 | 舌头顶住上齿后方的齿龈并突然释放<br><br>同一位置声带关是 /t/<br><br>同一位置声带开是 /d/                    |
| /tʃ/ | /dʒ/ | 龈后 + 舌尖 | 先做 /t/ 的阻塞, 再让它由 /ʃ/ 释放<br><br>同一位置声带关是 /tʃ/<br><br>同一位置声带开是 /dʒ/           |
| /k/  | /g/  | 软腭 + 舌后 | 舌头微碰下齿,   舌后部顶住软腭再释放<br><br>同一位置声带关是 /k/<br><br>同一位置声带开是 /g/                |

/tʃ/ /dʒ/ 严格说是破擦音（先塞后擦）, 总表把它们排进爆破音行, 是因为按**接触面位置**它们正好落在齿龈和软腭之间。

### 擦音

擦音只有一个阶段。清浊爆破音的差别也不只是声带振不振, 还在于**气憋在哪里**： 气流通过狭窄通道产生摩擦声。清浊成对, 同样从口腔前部排到后部; 只要有气就能一直发下去。

| 清音  | 浊音  | 两个接触面   | 发音技巧                                                                 |
| --- | --- | ------- | -------------------------------------------------------------------- |
| /f/ | /v/ | 上齿 + 下唇 | 上齿和下唇形成持续摩擦<br><br>两个表面不变, 声带关是 /f/<br><br>两个表面不变, 声带开是 /v/          |
| /θ/ | /ð/ | 上齿 + 舌尖 | 从 /f/ 出发, 保持上齿参与, 把舌尖向前伸来替换下唇<br><br>这个位置声带关是 /θ/<br><br>声带开是 /ð/    |
| /s/ | /z/ | 舌尖 + 齿龈 | 用持续摩擦拉长这个音<br><br>同一口腔位置声带关是 /s/<br><br>同一口腔位置声带开是 /z/               |
| /ʃ/ | /ʒ/ | 舌尖 + 龈后 | 从 /s/ 把舌头再往后移到齿龈后／硬腭前部, 保持摩擦<br><br>同一位置声带关是 /ʃ/<br><br>同一位置声带开是 /ʒ/ |

### 鼻音

两个接触面把口腔完全封死, 气流被迫从鼻腔出来。声带振动, 全部为浊音

| 音标  | 两个接触面   | 发音技巧                                                                |
| --- | ------- | ------------------------------------------------------------------- |
| /m/ | 上唇 + 下唇 | 双唇完全闭合, 口腔被封住, 气流被迫从鼻腔出来; 捏住鼻子声音应立刻中断;<br>堵点最前, 口腔共鸣空间最大、最饱满, 适合哼歌。 |
| /n/ | 舌尖 + 齿龈 | 舌头在上齿后方的齿龈嵴一带封住口腔, 气流从鼻腔出来; 捏住鼻子声音应立刻中断;<br>堵点在中间, 共鸣空间比 /m/ 小。     |
| /ŋ/ | 舌后 + 软腭 | 舌尖放松轻贴下牙内侧, 舌后上方拱起封住软腭, 气流从鼻腔出来; 捏住鼻子声音应立刻中断;堵点最后, 口腔里几乎没有共鸣, 接近纯鼻音。 |

### 落单/h/ 

总表第三行里**落单的一个**：它既不与鼻音同类, 也没有配对的浊音。

| 音标 | 两个接触面 | 发音技巧                                   |
| ---- | ---------- | ------------------------------------------ |
| /h/ | 声门 | 视频没有单独示范这个音的发音技巧, 只在总表里把它说明为 落单项：落单、无清浊配对。 |

### 边音/l/

气流从舌两侧通过。

| 音标  | 两个接触面                | 发音技巧                                                                                                                                                                                                                                                                 |
| --- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| /l/ | 舌尖 + 齿龈              | **清晰 L（Clear L [l]）**：位于元音前（*light, live, plan*）。从 /n/ 的全封闭位置出发：**舌尖紧贴上齿龈正中堵死前路**, 主动将**舌头两侧边缘下垂松开**, 声带震动让气流由两侧缝隙持续涌出（舌尖贴住时音已在响）; 舌身前推, 发声后舌尖**迅速向下、向口腔内部后撤脱离（绝非向前顶）**以顺势接入后面的元音, 声音清脆。                                                                             |
| /ɫ/ | 舌尖 + 齿龈<br>（辅以舌后+软腭） | **暗音 L（Dark L [ɫ] / 软腭化 L）**：位于元音后或音节尾（*call, milk, result*）, 分两种现实层次：<br>• **标准读法**：舌尖抵住齿龈不弹开, 舌后部抬向软腭方向拉但不接触, 舌中部下沉, 声音低沉;<br>• **口语元音化（L-vocalization）**：伦敦及英格兰东南部口音常见, 舌尖不碰齿龈, L 变成类似 [ʊ] 的后元音（*milk* [mɪʊk]、*apple* [ˈæpʊ]、*result* [rɪˈzɒʊt]）; 标准英音不这样读, 听懂即可。 |

元音 + 暗音 L [ɫ] → 辅音染色 / 元音化(前音元音受后接暗音 L 软腭化拖拽染色; 尤其 `/ʌ/` + l 常同化偏向 `/ɒ/` 或 `/o/`, 甚至暗音 L 直接元音化为 [ʊ])：

| 元音 + 暗音 [ɫ] → 辅音染色 / 元音化                                                                                         | 解释                                                          |
| :--------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- |
| The **result is** that it can't be grown in the northern or southern parts of the globe only around the equator. | **`[rɪˈzɒlt]`**：`result` 词尾暗音 L 软腭化, 元音 `/ʌ/` 后缩拖拽发为 `[ɒ]`。  |
| You can get lots of small dishes to share, which always works really **well** if you’re in a group.              | **`[wɒɫ]`**：`well` 词尾暗音 L 软腭化元音化, 元音 `/e/` 受圆唇过渡低化为 `[ɒ]`。   |
| ...and in future the **final stage** could even be carried out by drone, although at present this isn’t allowed. | **`[ˈfaɪnl' steɪdʒ]`**：`final stage` 中暗音 L 软腭化衔接, 词尾爆破音过渡阻气。 |

### 近音/r/、/w/、/j/

发音器官接近但不完全阻塞气流。

| 音标      | 两个接触面   | 发音技巧                                                                  |
| ------- | ------- | --------------------------------------------------------------------- |
| /r/     | 舌尖 + 龈后 | 舌尖上卷并后收但不形成阻碍, 气流从上卷舌尖上方通过<br><br>也可从 /ʃ/ 继续后移到摩擦消失, 或从 /n/ 抬起／后收舌尖来找 |
| /w/     | 双唇 + 软腭 | 从 /ʊ/ → /ə/ 的滑动出发, 但给嘴唇加强主动动作：嘴唇积极圆起、前推, 并快速滑向后面的元音                   |
| /j/     | 舌面 + 硬腭 | 从 /ɪ/ → /ə/ 的滑动出发, 但给舌头加强主动动作：舌面前部积极接近硬腭, 并快速滑向后面的元音                  |

三个都能从已经会的音派生出来：

| 目标      | 起点             | 怎么挪                                                                        |
| ------- | -------------- | -------------------------------------------------------------------------- |
| <br>/r/ | /n/<br><br>/ʒ/ | 同样从封死状态出发, 改成把舌尖翘起后收, 气从舌尖上方出去<br><br>舌尖继续后移, 移到找不到第二个接触面为止, 摩擦消失剩下的就是 /r/ |
| /w/     | /ʊ/→/ə/ 的滑动    | 就是这个双元音, 但给嘴唇加上强烈的主动运动                                                     |
| /j/     | /ɪ/→/ə/ 的滑动    | 就是这个双元音, 但给舌头加上强烈的主动运动                                                     |

 /w/ /j/ 叫"半元音", 是因为构造方式和元音完全一样（没有任何气流阻碍）。但英语把它们当辅音用——它们能像辅音一样待在音节里元音的两侧

**英音 (RP) /r/ 发音规则**：
- **词内**：后接元音才发（*red, agree*）; 后接辅音或独立词尾**不发**（*hard, car, water*）。
- **跨词**：词尾拼写含 r 遇后接元音时**复活连读**（*far away*, 详见连音篇）。
