# 考试内容

## 考试结构

| 部分     | 形式    | 时间    | 题量                        | 准备时间                          | 考察重点                  |
| ------ | ----- | ----- | ------------------------- | ----------------------------- | --------------------- |
| 自我介绍   | 与考官寒暄 | 约1min | 固定脚本                      | 无                             | **不计入分数**             |
| Part 1 | 基础问答  | 约4min | 3个大方面 × 每方面约3个小问题（共9~11问） | 无, 听完**立刻**作答                 | **fluency 流畅度**       |
| Part 2 | 独白陈述  | 约4min | 1个话题卡                     | **1min**（可做笔记）, 然后说满 **2min** | **idea & vocabulary** |
| Part 3 | 深入问答  | 约4min | 顺着Part2追问 **2~6** 个       | 无                             | **idea & vocabulary** |

## 自我介绍

考官的话术基本固定, 直接按脚本应对：

| 角色  | 内容                                                                                                         |
| --- | ---------------------------------------------------------------------------------------------------------- |
| 考官  | Good morning/afternoon/evening. Can you tell me your **full name**, please?                                |
| 考生  | Sure, my name is XXX. **You can call me XX.**                                                              |
| 考官  | Can I see your **identification**, please?（identification = 证件、准考证）                                        |
| 考生  | Yes / Absolutely / Sure / **Here you are.**                                                                |
| 考官  | Thank you, **that's fine**. Now in this first part, I would like to ask you some questions about yourself. |

注意点：

| 陷阱                              | 说明                                                                                                         |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **full name ≠ phone name**      | 考官问的是全名, 不是手机型号（真有同学答"华为"）                                                                                  |
| You can call me XX              | 不是必须说; 名字难发音时给个好叫的称呼。考官也可能主动问 **What shall I call you?**                                                    |
| **here you are ≠ here are you** | here are you 意思变成"你在这啊", 用错很尴尬                                                                              |
| **that's fine ≠ 夸你说得好**         | 意思是"行了、到此为止、我了解了"                                                                                          |
| 慎用 **fine**                     | 口语中 fine 暗含敷衍、"行吧随你"甚至不耐烦的贬义。回答 How are you 更自然的是 **I'm good / not bad / awesome / terrific**, 很少用 I'm fine |

## 6.5分案例

6.5分考生 fluency 和 pronunciation 都在 7 以上, 卡分点全是小错误：

| 类别 | 错误                               | 应该是               | 说明                                      |
| ---- | ---------------------------------- | -------------------- | ----------------------------------------- |
| 词汇 | candidates for my name             | options              | candidate 指人, 如总统候选人              |
| 词汇 | disgusting（形容牛仔裤）           | —                    | 太极端; disgusting 只能用于反胃的食物     |
| 词汇 | for natures                        | nature 不可数        | —                                         |
| 词汇 | 城市很 packed                      | crowded              | packed 指室内被塞满（地铁车厢、场馆可用） |
| 语法 | go to gym                          | go to the gym        | 介词冠词缺失是他最大扣分点                |
| 语法 | located at the southern part       | in the southern part | —                                         |
| 语法 | jeans... it is comfortable         | jeans 是复数用 they  | 买两条是 two pairs of jeans               |
| 语法 | 描述梦想家 it should be...         | 想象类话题用 would   | 题目本身就是 would 问的                   |
| 语法 | most of people                     | most people          | —                                         |
| 语法 | 考官问 Do you think..., 答 I agree | —                    | I agree 只能回答 Do you agree             |

结论：**低阶词句全对 + 点缀一点高阶词汇**, 就是我们背稿方向的两个支柱。9分近native视频听听就好, 不要模仿——那是硬实力, 短期提分要靠套路。

# 备考策略

## 基本方向

**关键心法：写逐字稿不是写作, 只是记录口语要说的内容。正确做法是——先念念有词, 再落笔记录。** 一旦"洗手端坐、认真打字", 写出来的东西多半书面化、难背。打字打的不是脑袋里想的, 而是**嘴巴里说的**。口语稿不讲究书面标点和连词规范, 但别把这些用法带进写作。

写稿流程：① 写出母版逐字稿 → ② 改成适应其他题目的子版本（每道只需新写约40%~50%）→ ③ 用 **Grammarly**（网页版+桌面版, 免费）自查语法。

个人化程度四档（按英语基础和时间选）：

| 档位         | 做法                                 |
| ---------- | ---------------------------------- |
| ① 直接背老师的稿子 | 最省事, 但别人写的略难背; 至少抄写一遍                |
| ② 替换部分语言   | 把绕口、不顺的句子换成自己的话                    |
| ③ 换例子      | 例子自己编, 好背、不撞车                       |
| ④ 换例子+换语言  | 用 Thesaurus+Collins 重造高级表达, 语言例子全原创 |

写的时候**第一反应想到什么就写什么**, 不要反复斟酌——想太多的答案背起来磕磕巴巴, 且第一反应在考场上忘了也容易重现。

## Part 1 基础问答

### 基础认知

Part1 共 3 个大题、10 个左右的小问题, 考官每换大题会说 **OK, let's talk about XX**。

| 大题        | 来源                                               | 确定性                   |
| --------- | ------------------------------------------------ | --------------------- |
| 第 1 个大题   | 【work/study】或【hometown/where do you live】**二选一** | 相对确定, 考官心情决定问哪个        |
| 第 2、3 个大题 | 考官从手上的【26 个大题】中任选其二                              | 不确定, 但**26 个大题都能提前拿到** |

→ 合计 **28 个**, 全部准备。考察重点是 **fluency**：**不需要拽文**, 尽量流畅、简短、用完整句子回答完即可。

**单题标准**

| 标准   | 内容                                               |
| ---- | ------------------------------------------------ |
| 长度   | 每小题 **2~3 句完整句子**（不能是单词/短语）, **30~40 词**          |
| 时间   | **15 秒左右**; 超过 20 秒可能被考官打断                        |
| 说完之后 | 充满自信、面带微笑看着考官, 不要再说了——接下来说的是没准备过的内容, 容易出错, **言多必失** |

### 技巧与示范

**正反例对比**

以 **Did you enjoy traveling by car when you were a child?** 为例：

| 反例   | 答案                                                                                                     | 问题                                 |
| ------ | -------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| 太短   | Yes.                                                                                                     | 一个词, 不到一秒                     |
| 太长   | I think the color of a car is significant to me mainly for 3 reasons. Firstly... Secondly...（写作文式） | 必被考官打断, 且难背                 |
| 太书面 | I prefer to **obtain** information from websites, which are **replete with**...                          | 发音没把握、记不下来, 口语里都不要用 |

正面例子：

> Yes, I loved it. When I was just ten years old, I traveled a lot by car: to the countryside, to the riverside, and even to another province. I really miss those days.

标准答案公式：**简明地回答问题 + 1~3 句进一步解释**。不需要高难词汇——Part1 只考 fluency（Part2/3 也只有冲7分以上才需讲究词汇）。写稿时**反而容易写难**, 要时刻用"好不好背、像不像口语"来检查。

**十大技巧**

全部以 **Did you enjoy traveling by car when you were a child?** 为例：

| 技巧                          | 示例                                                                                                  | 说明                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. **简短地回应问题**         | Yes, I loved it. / Absolutely, I liked it a lot. / No, not really. / I am not a big fan of XX         | 不能只是单词, 需完整句子; I am not a big fan of XX 是很口语的"我不是……的粉"                                                                                                                                                                                                                                                                                          |
| 2. **加一段自己的经历**       | used to do                                                                                            | 注意时态; 形容过去经常做的事推荐用 used to do（do 不用变形, 不容易犯错）                                                                                                                                                                                                                                                                                             |
| 3. **加一段评价收尾**         | I really miss those days. / Those days were a nightmare                                               | 口语化的"噩梦"=a nightmare。语法点：**主谓一致看主语**（Those days were a nightmare, 看 those days 不看 nightmare）; **experience** 作"经历"可数、作"经验"不可数                                                                                                                                                                                                     |
| 4. **平行结构（排比）⭐**     | to the countryside, to the riverside, and even to another province                                    | 部分成分相同（便于记忆回忆, 给大脑 0.00几秒缓冲）+ 部分成分不同（秀词汇）                                                                                                                                                                                                                                                                                            |
| 5. **缓兵之计用词（filler）** | You got me. / That's a tough question. / Well, that was like 10 years ago.                            | I am not very **familiar** with XX（发音要练熟）。一道题最多用一两句, 堆多显得刻意                                                                                                                                                                                                                                                                                   |
| 6. **对比与比较**             | Compared to traveling by bike, it's faster; compared to trains, you have much more freedom.           | **用了 compared to, 后面必须接比较级**; 多句用同一开头形成惯性, 便于记忆                                                                                                                                                                                                                                                                                             |
| 7. **替代经历**               | car 没经历 → 说 bike                                                                                  | 完全可行不扣分。雅思口语考交流, 不看回应是否滴水不漏                                                                                                                                                                                                                                                                                                                 |
| 8. **用现在和未来填充**       | I do it all the time / hope to do                                                                     | 题目问过去, 也可以用现在/未来内容填充, 好处是**时态更简单**                                                                                                                                                                                                                                                                                                          |
| 9. **找一个理由**             | because traveling by car is really exciting. Just imagine, the air, the speed, and all the scenery... | 理由句可以非常简单（又是平行结构）                                                                                                                                                                                                                                                                                                                                   |
| 10. **万精油理由**            | 放松自我 / 交朋友 / 长见识                                                                            | 找不到具体理由时用, **不到万不得已不用**（会失去针对性）。放松自我：escape from the daily pressure, have a break; 交朋友：making new friends, totally different life stories; 长见识：enriching experiences, have access to different knowledge, become **mentally mature**（褒义, 形容人=成熟见多饰广; 可换 **sophisticated**, 用出≈8分选手; 形容物才是"复杂精巧"） |

附：引用**他人观点**也是很好的撑内容方式, 但引完必须给自己的评价（同意/反对）。

**七个雷区**

| 雷区                   | 反例                                                                  | 说明                                                                                                                                                                                                                                                                                           |
| ---------------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 只说一个词          | Yes.                                                                  | 一个词不到一秒                                                                                                                                                                                                                                                                                 |
| 2. 说太多              | 三段论作文式回答                                                      | 会被打断且难背                                                                                                                                                                                                                                                                                 |
| 3. 用语太书面          | obtain / replete / unbiased                                           | 记不下来、发音不保                                                                                                                                                                                                                                                                             |
| 4. 无用套话堆砌        | As far as I am concerned, I think... / You know... / ...how to say... | **As far as I am concerned, I think...** 两者表意重复, 保留一个即可; **You know...** 后面只能接众所周知的事实, 不能接个人观点; **...how to say...** 后面该接较难的表达, 高手用它引出加分词汇（is, how to say, *the liberation of the soul*）, 接简单词就是硬凑（用错不算大错, 但暴露你在硬凑） |
| 5. 状语/介词结构堆太多 | 三重介词绕口                                                          | 改成分成两句说（此规则同样适用于 Part2/3）                                                                                                                                                                                                                                                     |
| 6. 连续形容词嵌套定语  | a modern, mysterious, and marvelous city                              | 记忆压力大; 改用 so 隔开变成平行结构：so modern, so mysterious, and so marvelous                                                                                                                                                                                                               |
| 7. 不自然的语音表现    | 机关枪匀速背稿                                                        | 来源：①没有断句（句间/句内成分间/难词前应停顿）; ②没有抑扬顿挫（每句适当起伏即可, 不用模仿谁）; ③一直不看考官（技巧：说完一个难词后看考官一眼, 别刻意演）                                                                                                                                      |

**一题多用的局限**

Part2 的"一个故事串起多题"在 Part1 不实用也没必要——各大题核心词离得太远（mirror、photos、cars……）, 且每小题只要2~3句, 单独准备不费时间。Part1 老老实实逐题准备即可。

**完整示范（Cars）**

**1) Did you enjoy traveling by car when you were a child?**
> Yes, I loved it. When I was just ten years old, I traveled a lot by car: *to the countryside, to the riverside, and even to another province*.（排比）I really miss those days.

**2) Would you generally prefer to be a driver or a passenger in a car?**
> *Umm... If I have to choose, I'd say* passenger.（缓兵之计）Being a passenger is much more relaxing than being a driver: *you don't have to focus on the direction, you don't have to pay attention to the speed limit*.（排比）

**3) How important is the color of a car to you?**
> Very important, I guess. I like black. *A lot of people say black is a noble color, and I agree.*（他人看法）If my car is black, it makes me look noble too, and that's great.

**4) What type of car would you most like to have in the future?**
> *Actually, I don't know the types, or the brands, of any cars.*（缓兵之计）For me, my car should be easy to drive, of course; and it should be black; and finally, it should be sturdy. I don't want to spend a lot of money on the repairs.

主题词：speed limit 限速 / noble 高贵的 / brand 品牌 / sturdy 耐用的 / repair 修理（此处作名词）

## Part 2 独白陈述

### 基础认知

**题目长相与流程**

题目以 **Describe a ...** 开头, 下方有 4 条 instructions（指令）作答参考。官方明确说过：**不完全按指令作答不扣分**, 只要大方向扣住最上面的题目即可; 但既然指令已写出, 按 4 个方向准备最省事。

| 流程               | 说明                                          |
| ---------------- | ------------------------------------------- |
| 1）考官给出 1 个问题（卡片） |                                             |
| 2）1min 准备, 可做笔记   | 准备充分的人是在**假装做笔记**——那一分钟其实是在回忆之前备好的内容, 不是临场构思 |
| 3）开始说 2min       | 没说够可能扣分, 且考官会追问 1-2 个**不算分**的问题（发挥不好还影响心态）   |

→ 策略：**稿子准备得长一些, 宁愿被考官打断, 也不要没说够时间**。被打断只是时间到了, 不是你说得差。

**考察重点**

| 维度         | 标准                        | 如何达成                                |
| ---------- | ------------------------- | ----------------------------------- |
| idea       | 有逻辑、较丰富                   | **紧跟 4 条指令逐条回应**——4 个层面天然就是 4 个逻辑层次 |
| vocabulary | 相关的**主题词汇** + 适当的**高级词汇** | 见下方母版分析                             |

Part1 的十大技巧在 Part2 通用, 但大可不必——有 4 条指令在, 跟着写就能保质保量。

词汇分三类：**主题词汇**（与本题紧密相关, 如网红题：influencer, browsing videos）、**亮眼表达①高级词汇**（intriguing, captivate, a daunting task）、**亮眼表达②口语化表达**（a piece of cake, deep deep down——中国学生反而普遍薄弱）。

### 技巧与示范

**母版三层分析法**

适用于所有 Part2 类别, 从一篇范文拆解出可复用的结构：

**层次一·词汇层**：把范文里的主题词汇和亮眼表达逐个标出, 明白自己在背什么。

**层次二·套路性句式**（把实词挖掉, 剩下的就是母版化结构, 换一批高级词填进去即成新句子）：

| 句式模板                                                                                                               | 用法说明                                                                    |
| ---------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| It was **so** A, **so** B, **and it** C-ed **me at once**                                                              | "如此A、如此B, 以至于立刻把我怎么样了"; B 程度须比 A 深; 结果动词处放高级词 |
| A, B, **and even** C(, sometimes)                                                                                      | 平行结构：撑字数 + 好记忆 + 秀词汇                                          |
| sb is **so** X, **it's like** everything ... **is just** Y **to him**, he is **almost, how to put it**, Z, **I guess** | how to put it（怎么说呢）制造思考感、自然引出高级词 Z                       |
| that's **more than** X, it's **very** X, it's **a** Y                                                                  | 程度三连递进; Y 是名词化的高级表达                                          |
| **He shared how he** A, **and how he** B, **and even how he** C                                                        | 展开细节的排比, 气势足、内容丰                                              |
| I was **X** ..., **no, I was more than X, I was Y**                                                                    | 自我打脸式递进：先说X, 否定自己, 再上一个程度更深的Y                        |
| I want to become X, become Y, and become Z **as well**                                                                 | 排比 + 程度递进                                                             |
| really + adj., **actually** + 更深的 adj.                                                                              | 后一个形容词程度必须比前一个深                                              |
| **I mean, come on**                                                                                                    | 唤起对方注意的口语插入语                                                    |

**层次三·故事的灵活性**：范文中母版性语言（保留）之外的部分, 换掉几个关键核心即成另一个故事（如聪明学长→美食姐姐, 重写只需几分钟）。替换时用同一套句式, 只换对应的高级词。

**查词工具**

| 工具                               | 用途               | 用法                                                                                          |
| ---------------------------------- | ------------------ | --------------------------------------------------------------------------------------------- |
| **Thesaurus**（thesaurus.com）     | 找同义词群         | 输入 surprised → 颜色越深的同义词意思越接近                                                   |
| **柯林斯词典**（有道内置 Collins） | 判断候选词程度深浅 | 查 stunned → "extremely shocked", 比 surprised 深得多; **英文释义比中文翻译更能看出程度深浅** |

组合用法：Thesaurus 找同义词 → Collins 确认程度更深、方向一致 → 填入递进句式。

会不会撞车不用太担心：不同考场、模板可自行改写、非模板部分套个性化故事, 实际展示内容也会和准备的有出入。

## Part 3 深入问答

顺着 Part2 话题继续往深问, 题目**拿不到**（临场发挥, 靠听）、抽象、常结合社会现实; 单个回答越长, 考官能问的问题越少, 仍是 **say as much as you can**。详细的定位、备考策略与七大常见问法模板见 [[f. 深入问答]]。
