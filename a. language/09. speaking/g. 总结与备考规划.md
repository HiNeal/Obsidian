# 总结与备考规划

## 三个部分速览（考前最后过一遍）

| | Part1 | Part2 | Part3 |
|--|-------|-------|-------|
| 定位 | 暖身, 短平快 | 不被打断的自留地 | **6分+选手的主战场** |
| 回答长度 | 2~3句 / 15~20秒 | 说满 2min 直到被打断 | 每题尽量 2min（约250词）→ 最多被问 2 题 |
| 准备时间 | 无（可做1秒思考状） | 1min（用**关键词**把背过的内容记在纸上, 忘词时看一眼） | 无 → 更依赖模板背熟 |
| 有无真题 | 有 | 有 | 基本没有（回忆题当练习即可, 别背记压力） |
| 关键提醒 | 说完就**闭嘴**微笑看考官, 言多必失 | 别自己看表计时（分心）, 一直说到被打断 | 模板占 90~150 词≈1分钟, 你只需再临场发挥 1 分钟 |

Part2 补充：没说够 2min 可能扣分且被追问——追问表现不计分, 但没准备过、答不好**影响后面心情**, 所以稿子写长一点。

## 评分标准与应对

四项标准全部指向同一个动作：**自然而然地背稿子**。

| 官方标准   | 内涵                                                                                     | 应对                                         |
| ---------- | ---------------------------------------------------------------------------------------- | -------------------------------------------- |
| 流利度     | 整体顺畅即可, **可以略有思考和停顿**; 6.5分韩国小哥语速很慢照样6.5——语速自然就行, 不用快 | 考前把稿背熟, 考场自然输出                   |
| 连贯性     | 从头到尾围绕主题, 不东拉西扯                                                             | 提前准备的稿子**天然不偏题**                 |
| 词汇多样性 | 主题词汇（influencer）+ 高分表达（高级词 fleeting / 口语表达 you can totally tell）      | 考场上根本想不起来——**全部提前写进稿子**     |
| 语法多样性 | 官方特别强调**时态丰富**（现在/过去/将来/完成）; 句式同理                                | 写稿时有意融入多种时态和句式                 |
| 发音       | 英音美音混杂、中国口音都行, **不影响交流即可**                                           | 老师纠音只纠"影响理解"的音; 不必追求漂亮口音 |

## 备考时间规划

### 各部分时间占比

**Part2 分最多时间**（Part1 + Part3 加起来都没它多）——不是因为难, 是因为**量大**。

| 部分  | 准备策略                                                                             |
| ----- | ------------------------------------------------------------------------------------ |
| Part1 | 记**第一反应**的观点, 不写猎奇观点（背诵负担大且没必要）; 甚至可以不写稿, 脑内过两遍 |
| Part2 | 母版 + 串题逐字稿, 主力投入                                                          |
| Part3 | 不用写太多稿; 重点是**把语言模板背到滚瓜烂熟** + 拿高频题练"怎么套"                  |

### 每部分内部的时间分配

| 环节                        | 占比    |
| --------------------------- | ------- |
| 写逐字稿                    | 30%     |
| 背诵                        | 30%     |
| **反复熟悉 + 套用不同题目** | **40%** |

- 考场上最亏的状态："这题我准备过, 但印象不深了"——一紧张更想不起来。**什么都没准备还死得瞑目, 准备了却不熟最冤**
- 复习是越来越轻松的事：每天安排三遍熟悉, 第二天就很熟了; 多数人只在写稿当天看一遍, 之后不复习——最可惜
- 背诵技巧（用聪明学长稿子里的原话）：**take advantage of different locations to consolidate your memories**——同一份稿子在客厅、书房、卧室、走廊换着地方背, 加固记忆

## 考场 Tips

### 如何不显得在背稿

| 技巧           | 做法                                                                                |
| -------------- | ----------------------------------------------------------------------------------- |
| 正常断句       | 句间断; 句内成分间断：Well, // I used to do that // a lot                           |
| 难词前做思考状 | It's kind of, // boring——难词前停顿一下, 符合正常人的思维过程（即使你背得滚瓜烂熟） |
| 抑扬顿挫       | 不强求, **别太平**即可; 过度模仿语调会打乱节奏, 且语调平不扣分                      |
| 眼神交流       | 不强求：别全程躲避考官, 也别死盯                                                    |

### 没听懂问题怎么办 ⭐

不要用 Excuse me / Pardon / Could you repeat that for me——考官只会**原样再读一遍**。你没听懂不是因为音量小或语速快（考官受过专业训练）, 而是**有单词或短语没懂**。正确做法是请考官**解释**：

> ① 完全没懂：
> Sorry, I think I didn't understand it very well. Could you please explain it a little bit?
>
> ② 懂了一部分、不确定：
> OK, if I got it right, it means ......, right? （对了考官会肯定你; 错了他会进一步解释）

### 遇到没准备过的题怎么办

- 官方建议：从侧面说（原因/结果/解决办法）——**不实操**：临场既要想出因果对策又要用英语说出来, 做得到的话口语早不愁了
- 老师建议：**把题目尽量往自己准备过的方向拽**。例：问"一个运动员", 就用你准备过的明星/歌手/科学家（都是人物类）。稍微偏题, 也远好过说不出话、或临场硬编一堆语法错误

## 考后：从应试到真实能力

老师最后的心里话（呼应 Day1 的"功利应试路"）：

- 这套应试方法对**真实口语能力**的提升大约只有 5%——以后老外问你"最近在关注什么网红", 你能脱口而出聪明学长, 仅此而已
- 考完想真正提升口语：多看美剧、做摘抄、做积累、配音模仿语音语调——这些是**长期活**, 应试期间不要干
- 人生建议——想清楚口语在你人生中扮演什么角色：

| 场景                                         | 该追求什么                                                                                             |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 口语是工作日常（如外企, 天天和外国人打交道） | **地道性、准确性**。口音完全不重要——外企人人有口音, 你没有才奇怪                                       |
| 口语只是敲门砖（面试环节、考研加分项）       | 把"花架子"做好：**口音、流畅度**。门外汉不会深究你的英语功底, 但会听表面的东西——好口音给人好的第一印象 |

> 祝你像攻克雅思一样, 攻克人生中一个又一个困难。
