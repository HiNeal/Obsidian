# 小作文写法

| 环节 | 核心结构与任务 | 写作要点与展开 |
| --- | --- | --- |
| 段落结构 | 开头段 → Overview → Detail ×2 (不另写结尾段) | 按内容分组, 不按线条数量分段 |
| 开头段 | 改写题目, 客观描述图表内容 (不发表观点) | 改写示例: per person → per capita; 1967–2007 → a 40-year period |
| Overview | 用 Overall 引出主要特征, 具体数据留给 Detail | 动态数据重点看 **趋势 / 拐点 / 极值**<br>常用表达: experience a steady rise / witness a drop / remain the highest or lowest / throughout the period |
| Detail (×2) | 对象分组, 每组一段; 用具体数据支撑趋势与比较 | 轮换主语视角: each person → the figure → the quantity |
