# 短语

| 短语 | 释义 | 意群 | 评分 |
| --- | --- | --- | --- |
| fat chance | 绝无可能(非常非正式) | **Fat chance** (very informal) means almost no chance. | 0 |
| head a team | 领导团队 | Jo **heads a team** working on crime prevention. | 0 |
| hopping mad | 气得跳脚的(非正式) | His father was **hopping mad** | 0 |
| foot the bill | 买单 | the company is **footing the bill** | 0 |
| light reading | 轻松读物 | So **light reading** is reading material that is not serious. | 0 |
| a slim chance | 渺茫的机会 | If someone has **a slim chance** of doing something | 0 |
| hit the rocks | 触礁, 告吹 | if their relationship **hit the rocks** | 0 |
| a heavy burden | 沉重的负担 | **A heavy burden** can be either something heavy to carry or a difficult responsibility | 0 |
| a weighty tome | 一本厚重的大部头 | A **weighty tome**, however, would only be used to mean a book with difficult content. | 0 |
| weighty matters | 重大事务 | in **weighty matters** or weighty problems | 0 |
| run into trouble | 陷入麻烦 | he would **run into trouble** at work too | 0 |
| cast light on ... | 阐明 ... | a writer **casts light on a situation** | 0 |
| shoulder the blame | 承担责任 | Alice decided to **shoulder the blame**. | 0 |
| with a light heart | 心情轻松地 | If you do something **with a light heart**, you feel carefree and happy. | 0 |
| have an eye for ... | 对 ... 有眼光 | Gina **has an eye for** detail | 0 |
| heavy responsibility | 重大的责任 | heavy can be used to mean serious or difficult, as in **heavy responsibility** | 0 |
| run into difficulties | 遇到困难 | James did a lot of partying in his final year and **ran into difficulties** with his course. | 0 |
| face (up to) the facts | 正视事实 | It's time you **faced (up to) the facts**. | 0 |
| keep ... on ...'s toes | 让 ... 保持警觉 | Having three sons under the age of five **keeps** Jana **on her toes**. | 0 |
| jump to the conclusion | 贸然下结论 | Some people **jumped to the conclusion** that this was because | 0 |
| go hand in hand with ... | 与 ... 相伴而生 | Unemployment **goes hand in hand with** social unrest. | 0 |
| walk straight into a job | 轻松找到工作 | he **walked straight into a job** in an excellent company | 0 |
