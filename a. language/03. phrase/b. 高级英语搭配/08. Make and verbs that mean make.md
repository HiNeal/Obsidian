# 短语

| 短语 | 释义 | 意群 | 评分 |
| --- | --- | --- | --- |
| do research | 做研究 | Lana made some interesting research into her family roots – **did … research** | 0 |
| have a party | 举办派对 | We're going to make a party on Saturday – **have a party** | 0 |
| make enemies | 树敌 | you'll **make** a lot of **enemies** | 0 |
| make an offer | 出价 | we've decided to **make an offer** on it | 0 |
| turn a profit | 盈利 | our company should **turn a profit** for the first time | 0 |
| coin a phrase | 创造新说法 | I wonder who **coined the term** 'blogging'. | 0 |
| make an escape | 溜走 | I will try and **make an** early **escape**. | 0 |
| make an attempt | 尝试 | The team **made** several **attempts** to climb the mountain | 0 |
| make a proposal | 提出提议 | I'd like to **make a proposal**. | 0 |
| stage a protest | 举行抗议 | The students **staged a protest** against rising tuition fees. | 0 |
| run up curtains | 赶制窗帘 | I'm going to **run up** some **curtains** for my new room. | 0 |
| make a discovery | 有所发现 | Our research team has **made** an important **discovery** | 0 |
| rustle up a meal | 匆忙做出一餐饭 | It took Sam ten minutes to **rustle up a meal**. | 0 |
| make calculations | 进行计算 | try to ensure you **make** all the **calculations** correctly | 0 |

| lodge a complaint | 提出投诉 | Several people have **lodged a complaint** about the receptionist's rudeness. | 0 |
| make a contribution | 做出贡献 | I think that I could have/give a contribution to the project – **make a contribution** | 0 |
| make a habit of ... | 养成 ... 的习惯 | It's a good idea to **make a habit of** switching off the lights | 0 |
| create an atmosphere | 营造氛围 | The lanterns in the garden **create a** romantic **atmosphere**. | 0 |
| make some suggestions | 提出一些建议 | I would like to do/give some suggestions – **make some suggestions** | 0 |
| make a formal apology | 正式道歉 | I expect you to give a formal apology – **make a** formal **apology** | 0 |
| make a success of ... | 把 ... 做成功 | I hope that they'll **make a success of** their new restaurant business. | 0 |
| make these arrangements | 做这些安排 | Thank you very much for doing these arrangements – **making these arrangements** | 0 |

| create a good impression | 留下好印象 | if you want to **create a good impression** | 0 |
