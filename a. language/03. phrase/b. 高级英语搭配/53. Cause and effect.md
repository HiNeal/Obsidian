# 短语

| 短语 | 释义 | 意群 | 评分 |
| --- | --- | --- | --- |
| root cause | 根本原因 | Mass unemployment is believed to be the **root cause** of the riots. | 0 |
| ill effects | 不良影响 | not expected to suffer any long-term **ill effects** | 0 |
| wreak havoc | 造成严重破坏 | This wind will **wreak havoc** with my flowers! | 0 |
| plant doubts | 埋下疑虑 | they **planted doubts** in her mind | 0 |
| primary cause | 主要原因 | a virus is the **primary cause** of this type of cancer | 0 |
| give a reason | 给出理由 | he refused to **give me a reason** | 0 |
| desired effect | 预期效果 | the reforms to produce the **desired effect** | 0 |
| spell disaster | 预示灾难 | The strike could **spell disaster** for the country. | 0 |
| drive ... crazy | 把 ... 逼疯 | it's enough to **drive** anyone **crazy**! | 0 |
| breed resentment | 滋生怨恨 | If teachers show favouritism, it **breeds resentment**. | 0 |
| provoke an outcry | 引起强烈抗议 | decision to raise income tax **provoked an outcry** | 0 |
| compelling reason | 令人信服的理由 | There must have been some **compelling reason** surely. | 0 |
| dire consequences | 严重后果 | He must have known there'd be **dire consequences**. | 0 |
| prompt speculation | 引发猜测 | The film star's photo **prompted speculation** | 0 |
| establish the cause | 查明原因 | We have yet to **establish the cause** of this latest outbreak | 0 |
| produce the results | 产生结果 | The advertising campaign didn't **produce the results** we hoped for. | 0 |
| render ... obsolete | 使 ... 过时 | Email **rendered** the fax machine **obsolete**. | 0 |
| contributing factor | 促成因素 | his parents' financial problems might be a **contributing factor** | 0 |
| demand an explanation | 要求解释 | she'll **demand an explanation** | 0 |
| have a knock-on effect | 产生连锁反应 | have **had a knock-on effect** on departures all day | 0 |
| set the wheels in motion | 启动进程 | you can **set the wheels in motion** by filling in this form | 0 |
| feel the full effect of ... | 感受到 ... 的全部影响 | before we **feel the full effect** of the rise in interest rates | 0 |
| face the consequences of ... | 面对 ... 的后果 | make him **face the consequences** of his actions | 0 |
