# 短语

| 短语 | 释义 | 意群 | 评分 |
| --- | --- | --- | --- |
| long-winded | 冗长啰嗦的 | a story/lecture/speech is **long-winded** | 0 |
| a long haul | 漫长艰难的过程 | a task or a process is going to be **a long haul** | 0 |
| a long face | 愁眉苦脸 | someone has **a long face** | 0 |
| go a long way | 大有前途 | I think Heloise will **go a long way** | 0 |
| come a long way | 取得很大进步 | Kyoko has really **come a long way** since she first started learning English | 0 |
| long time no see | 好久不见 | **Long time no see!** | 0 |
| it's a long story | 说来话长 | **It's a long story.** | 0 |
| go to any lengths | 不择手段 | He would **go to any lengths** to avoid meeting Eva | 0 |
| go back a long way | 相识已久 | Helen and I **go back a long way**. | 0 |
| go to great lengths | 不遗余力 | She always **goes to great lengths** to make us feel welcome. | 0 |
| a list as long as ... arm | 长长的清单 | I've got **a list as long as your arm**! | 0 |
| to cut a long story short | 长话短说 | **To cut a long story short**, Peter fell in love with the restaurant owner | 0 |
| how long is a piece of string | 这没法说 | **How long is a piece of string?** | 0 |
| take a long, hard look at ... | 仔细审视 ... | I think we should **take a long, hard look** at the cost of all this. | 0 |
