# 形容词句子成分

| 功能       | 说明              | 例子                                         |
| -------- | --------------- | ------------------------------------------ |
| 前置定语     | 直接放在描述对象前       | a hungry rabbit                            |
| 后置定语     | 修饰复合不定代词; 形容词短语 | somebody nice; carrots good for the rabbit |
| 表语（主语补语） | 系动词 + 形容词       | The rabbit is hungry.                      |
| 宾语补语     | 补充说明宾语的状态       | Carrots make rabbits happy.                |
| 状语       | 表现主语的状态         | The rabbit came home, tired and hungry.    |

# 前置定语

多个形容词做前置定语时遵循特定顺序。中英文顺序往往不同：

| 顺序 | 类别 | 例子 |
| ---- | -------------------------- | --------------------------------- |
| 1    | 限定词（冠词、物主代词等） | a, the, my                        |
| 2    | 主观特征                   | beautiful, good, lovely, handsome |
| 3    | 尺寸                       | big, small, large, little         |
| 4    | 形状                       | round, square, flat               |
| 5    | 新旧                       | new, old, young                   |
| 6    | 颜色                       | black, white, red                 |
| 7    | 来源/国籍                  | Chinese, American, French         |
| 8    | 材料/质地                  | wooden, metal, plastic            |
| 9    | 用途                       | —（紧跟名词）                     |

从第 3 层（尺寸）开始都是客观描述。例：

> a beautiful big round new black Chinese wooden table
> a little white rabbit（✅ 自然） vs a white little rabbit（意思对但怪）

# 后置定语

修饰复合不定代词（somebody, anybody, everything, nothing 等）时形容词后置：

> somebody nice, anybody absent, everything possible, nothing wrong

形容词短语作后置定语 = 定语从句缩减：

> carrots good for the rabbit = carrots that are good for the rabbit;
> the rabbit eager to eat carrots = the rabbit that is eager to eat carrots;
> the rabbit busy eating carrots = the rabbit that is busy eating carrots;

# 表语（主语补语）

以 a- 开头的形容词通常只做表语：

| 只做表语 | 做定语要换词      |
| -------- | ----------------- |
| alive    | a living rabbit   |
| asleep   | a sleeping rabbit |
| alone    | a lonely rabbit   |
| ill      | a sick rabbit     |
| well     | a healthy rabbit  |

少数情况可做后置定语：the only rabbit alive（唯一活着的兔子）

# 复合形容词

| 构成方式 | 例子 | 相当于 |
| ----------------------- | ---------------------- | -------------------------------- |
| 形容词 + 形容词         | a red-hot coal         | —                                |
| 形容词 + 现在分词       | a good-looking rabbit  | —                                |
| 形容词 + 过去分词       | a new-born baby        | —                                |
| 副词 + 形容词           | all-round              | —                                |
| 副词 + 现在分词         | hard-working           | —                                |
| 副词 + 过去分词         | recently-built         | —                                |
| 形容词 + 名词 + -ed     | a white-haired man     | a man whose hair is white        |
| 形容词 + 名词 + -ed     | a kind-hearted woman   | a woman whose heart is kind      |
| 形容词 + 名词（无 -ed） | a long-distance call   | —                                |
| 数词 + 名词             | a one-way street       | —                                |
| 名词 + 形容词           | a snow-white rabbit    | a rabbit that is white like snow |
| 名词 + 现在分词         | a carrot-eating rabbit | a rabbit that eats carrots       |
| 名词 + 过去分词         | a heart-broken rabbit  | a rabbit whose heart is broken   |

⚠️ 带 -ed 的通常对应定语从句用 whose, 多用于修饰人或动物。

# 比较级

## 规则变化

| 原级      | 比较级         | 最高级         | 规则                 |
| --------- | -------------- | -------------- | -------------------- |
| tall      | taller         | tallest        | 单音节 + -er/-est    |
| big       | bigger         | biggest        | 重读闭音节双写尾字母 |
| happy     | happier        | happiest       | 辅音 + y → ier/iest  |
| late      | later          | latest         | 以 e 结尾 + -r/-st   |
| beautiful | more beautiful | most beautiful | 多音节加 more/most   |

## 不规则变化

| 原级      | 比较级          | 最高级            |
| --------- | --------------- | ----------------- |
| good/well | better          | best              |
| bad/ill   | worse           | worst             |
| many/much | more            | most              |
| little    | less            | least             |
| far       | farther/further | farthest/furthest |
| old       | older/elder     | oldest/eldest     |

## 比较句型

| 句型 | 结构 | 例子 |
| -------- | -------------------------- | ------------------------------------------------- |
| 相等     | as + 原级 + as             | The rabbit is as smart as the wolf.               |
| 否定相等 | not as/so + 原级 + as      | The rabbit is not as smart as the wolf.           |
| 超越     | 比较级 + than              | The rabbit is smarter than the wolf.              |
| 倍数     | 倍数 + as + 原级 + as      | This carrot is twice as big as that one.          |
| 越来越…  | 比较级 + and + 比较级      | The rabbit becomes smarter and smarter.           |
| 越…越…   | the + 比较级, the + 比较级 | The more carrots he eats, the smarter he becomes. |

## 最高级句型

| 句型 | 例子 |
| -------------------------- | -------------------------------------------------------- |
| the + 最高级 + 范围        | The rabbit is the smartest of all the animals.           |
| one of the + 最高级 + 复数 | The rabbit is one of the smartest animals in the forest. |
| the + 最高级 + 完成时定语  | This is the biggest carrot I have ever seen.             |
