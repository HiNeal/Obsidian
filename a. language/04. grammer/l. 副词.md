 
# 修饰对象

副词(adverb) = ad（朝向）+ verb（动词）= 修饰动词的词, 但实际上还能修饰其他副词、形容词、整个句子
 
| 修饰对象                   | 位置  | 例子                                    |
| ---------------------- | --- | ------------------------------------- |
| ==副词== + 动词 + ==副词==   | 前后  | The rabbit **often** runs **fast**.   |
| ==副词== + 形容词           | 前面  | newly developed space                 |
| ==副词== + 副词            | 前面  | The rabbit runs **very** fast.        |
| ==副词== + 整个句子 + ==副词== | 前后  | **Fortunately**, the rabbit survived. |

# 句子成分

副词主要充当状语, 但也可以充当表语、定语、宾语补语：

| 句子成分 | 说明 | 例子 |
| ---- | -------------- | ----------------------------- |
| 状语 | 修饰动词/形容词/副词/整句 | The rabbit runs **fast**. |
| 定语 | 放在被修饰名词后 | The rabbit **here** is smart. |
| 宾语补语 | 补充说明宾语 | Let me **in**. |
| 表语 | 在系动词 be 后 | The wolf is **abroad**. |

# 副词构成

| 构成方式 | 例子 |
| --------------- | -------------------------------------------- |
| 与形容词同形 | fast, hard, early, late, daily |
| 本身就是副词 | fast, hard, soon, often, now, here |
| adj. + -ly | quick → quickly, beautiful → beautifully |
| -le → -ly | simple → simply, gentle → gently |
| -ic → -ically | basic → basically, automatic → automatically |
| 辅音 + y → i + ly | happy → happily, easy → easily |

形容词和副词拼写相同, 但意义不一定相同, 分四种情况：

| 类型 | 形容词 | 副词 | 例子 |
| ------ | ----------------------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 同拼同义 | fast（快的） | fast（快地） | a fast rabbit → runs fast |
| 同拼异义 | pretty（漂亮的）<br><br>hard（硬的; 困难的） | pretty（相当）<br><br>hard（努力地; 猛烈地） | a pretty wolf → pretty smart<br><br>a hard question → works hard / raining hard |
| +ly 同义 | quick | quickly | a quick runner → runs quickly |
| +ly 异义 | large（大的）<br><br>hard（硬的; 困难的）<br><br>late（迟的） | largely（基本上）<br><br>hardly（几乎不）<br><br>lately（最近） | a large carrot → I largely only eat carrots<br><br>works hard → hardly works（几乎不工作）<br><br>arrived late → haven't seen him lately |

# 副词类型

## 方式副词

表示动作发生的方式。最常见的位置是句末

| 方式副词  | 意群                        | 释义 |
| --------- | --------------------------- | ---- |
| fast      | The rabbit runs **fast**.   | 快   |
| well      | The rabbit sings **well**.  | 好   |
| hard      | The rabbit works **hard**.  | 努力 |
| badly     | He plays **badly**.         | 差   |
| slowly    | The rabbit eats **slowly**. | 慢   |
| carefully | Drive **carefully**.        | 小心 |

## 程度副词

表示动作或性质的程度。一般放在被修饰词之前

| 程度副词        | 意群                                | 释义                         |
| --------------- | ----------------------------------- | ---------------------------- |
| too             | It's **too** hot.                   | 太                           |
| very            | The rabbit is **very** smart.       | 非常                         |
| quite           | It's **quite** good.                | 相当                         |
| ==rather==      | It's **rather** cold.               | 相当; 颇为; 更确切地说       |
| almost          | I **almost** ate it.                | 几乎                         |
| ==exclusively== | It was **exclusively** carnivorous. | 仅仅; 专门地; 纯粹地; 独占地 |

enough 特殊——修饰形容词/副词时放后面：

> The rabbit is smart enough.
> The rabbit runs fast enough.
## 地点副词

表示动作发生的地点。常放句末, 也可以放句首表强调：

| 地点副词   | 意群                                          | 释义 |
| ---------- | --------------------------------------------- | ---- |
| here       | **Here** you can relax.                       | 这里 |
| there      | **There** goes the rabbit.                    | 那里 |
| abroad     | The rabbit went **abroad**.                   | 国外 |
| upstairs   | The rabbit went **upstairs**.                 | 楼上 |
| everywhere | **Everywhere**, the rabbit looks for carrots. | 到处 |
| downstairs | The rabbit is eating **downstairs**.          | 楼下 |

地点副词有时候放句首表强调：

> Here you can relax and forget about all your troubles.
> There goes the rabbit!

## 时间副词

表示动作发生的时间。常放句尾, 有时放在句首或句中。

| 时间副词        | 意群                                                                     | 释义           |
| ----------- | ---------------------------------------------------------------------- | ------------ |
| now         | The rabbit is eating **now**.                                          | 现在           |
| yet         | The rabbit hasn't eaten **yet**.                                       | 还（否定/疑问）     |
| then        | The rabbit was young **then**.                                         | 那时           |
| soon        | The rabbit will come **soon**.                                         | 不久           |
| today       | What is today a simple children's toy has a surprisingly rich history. | 今天           |
| already     | The rabbit has **already** eaten.                                      | 已经           |
| ==onwards== | from the 1970s **onwards**                                             | 从某时起以后; 向后延续 |
| recently    | I **recently** saw a rabbit.                                           | 最近           |

## 频率副词

表示动作发生的频率。位置：实义动词前, be/助动词/情态动词后。

| 频率副词                | 意群                                                                            | 释义             |
| ----------------------- | ------------------------------------------------------------------------------- | ---------------- |
| often                   | The rabbit **often** eats carrots.                                              | 经常             |
| never                   | The rabbit **never** eats meat.                                                 | 从不             |
| always                  | The rabbit **always** eats carrots.                                             | 总是             |
| seldom                  | The rabbit **seldom** eats meat.                                                | 很少             |
| usually                 | The rabbit **usually** eats carrots.                                            | 通常             |
| sometimes               | **Sometimes** the rabbit eats carrots.                                          | 有时             |
| ==more often than not== | **More often than not**, data is spread across different government departments | 往往; 多半; 通常 |
| from time to time       | We all do it **from time to time**.                                             | 不时, 有时       |

否定句中的位置不同, 意思也有差别：

> The rabbit doesn't always eat carrots.（不总是吃）
> The rabbit always doesn't eat carrots.（总是不吃）

## 疑问副词

引导疑问句, 对动作的不同方面提问：

| 疑问副词 | 意群                                   | 释义                                |
| -------- | -------------------------------------- | ----------------------------------- |
| why      | **Why** does the rabbit eat carrots?   | adv. 为什么（问原因）<br><br>原因   |
| when     | **When** does the rabbit eat carrots?  | adv. 什么时候（问时间）<br><br>时间 |
| where    | **Where** does the rabbit eat carrots? | adv. 在哪里（问地点）<br><br>地点   |
| how      | **How** does the rabbit eat carrots?   | adv. 怎样（问方式）<br><br>方式     |

**疑问副词（why, when, where, how）**：仅用于修饰动作, 在句中充当**状语**（询问时间、地点、原因、方式）

**疑问代词（what, who, whom, which, whose）**：不是副词, 在句中充当**主语、宾语、表语**等名词性核心成分

> ❌ The rabbit was hungry, therefore he ate a carrot.（逗号不可直接连接）
> ✅ The rabbit was hungry; therefore, he ate a carrot.（分号）

**therefore** 

在学术阅读与高阶写作中, therefore 常置于系动词（be 动词）或助动词之后, 使前述主语更突出、行文衔接更流畅：
> The public's task is **therefore** to identify which links in the supply chain are sensitive to public pressure.（公众的任务因此是去识别供应链中究竟哪些环节对公众压力敏感。）


**however**

若在句子中（前后有逗号）, 其对比/转折的是**前一个句子**与**当前 however 所在的整个句子**, 而非仅对比它前后紧邻的词。
> Bone tissue is constantly being remodeled, meaning that bone is added or removed, depending on nutrient availability and the stress that the bone is under. Female polar bears, **however**, undergo extreme conditions during every pregnancy.（这里 however 并非仅对比 polar bears, 而是对比前一句中“普通骨骼的不断重建”与本句中“母熊在怀孕期的极端条件”。）


**otherwise** 

- **表条件转折（否则 / 要不然）**：连接副词, 表示不这样做会带来的后果：
> Eat carrots; **otherwise**, you'll be hungry.（快吃胡萝卜, 否则你会挨饿。）

- **表反向/否定（并非如此 / 相反地）**：在学术阅读中极高频修饰动词（如 `suggest / prove / indicate otherwise`）, 用于推翻或驳斥前文观点：
> 'It might be what we find interesting about this story is that it's got this survival-relevant information in it,' says anthropologist Jamie Tehrani. **But his research suggests otherwise.**（特赫拉尼的研究表明事实并非如此——以此直接否定了前文的传统观点。）

- **表范围与例外（在其他方面 / 除此之外）**：常置于形容词或过去分词前, 表示除了某个特例/瑕疵外其余均如何：
>The rabbit had a small scratch, but was **otherwise** unharmed.（兔子受了点轻微擦伤, 但在其他方面毫发无损。）


**rather**

- **表对比与反驳转折（恰恰相反 / 反之 / 而是）**：置于句首（通常后接逗号）作为句子连接副词, 用于**先驳斥/推翻前文的错误假设、迷思或传统看法**, 进而引出作者自身的**正面立论**（功能等同于 *On the contrary / Instead*）：
> Chapter seven tackles the 'bedrock myth', the assumption that the absence of bedrock is the reason for skyscrapers not being built... **Rather**, Barr argues that while deeper foundation costs were higher, they represented only a small fraction of the cost of development.（第 7 章破解了“基岩神话”这一传统假设……**恰恰相反/而是**, Barr 论证道：更深的地基成本在整体开发成本中仅占极小一部分。）

- **表程度修饰（相当 / 颇为）**：置于形容词或副词前, 相当于 *fairly / quite*：
> It's **rather** cold today.（今天相当冷。）

- **表纠正与补充说明（or rather / 或者更确切地说）**：用于修正前文用词或表述：
> The result is useful, **or rather**, essential.（这个结果很有用, 或者更确切地说, 是至关重要的。）

# 短语动词 (Phrasal Verbs)

由**动词 + 副词小品词**（如 *out, away, up, down, off, on, back*）构成的固定组合, 整体作为一个动词使用, 表达特定的动作或引申义。

**宾语位置**：
1. **普通名词**：置于副词后或中间均可：
   > turn off the light = turn the light off
2. **人称代词（*it / them / him / her* 等）**：**必须且只能置于动词与副词小品词之间**：
   > ✅ turn **it** off / ❌ turn off it
3. **与介词动词对比**：短语动词后接副词（代词插中间）; 介词动词（如 *depend on*）后接纯介词, 代词绝不可放中间：
   > ✅ depend on **them** / ❌ depend them on
