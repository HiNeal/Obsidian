英语以三位为一组（hundred / thousand / million / billion）, 与中文四位分组不同。

| 数量级 | 单位 | 例子 |
| ------ | -------- | ----------------------------------- |
| 百     | hundred  | 100 → one hundred                   |
| 千     | thousand | 1,000 → one thousand                |
| 万     | thousand | 10,000 → ten thousand（英语无"万"） |
| 十万   | thousand | 100,000 → one hundred thousand      |
| 百万   | million  | 1,000,000 → one million             |
| 千万   | million  | 10,000,000 → ten million            |
| 亿     | million  | 100,000,000 → one hundred million   |
| 十亿   | billion  | 1,000,000,000 → one billion         |

| 规则 | 例子 |
| ------------------------------- | ------------------------------------------------- |
| 几十几用连字符连接              | 21 → twenty-one, 66 → sixty-six                   |
| hundred/thousand/million 不加 s | 300 → three hundred（不是 hundreds）              |
| and 放在最后一级之前            | 365 → three hundred and sixty-five                |
| 读数从大到小逐位读              | 3,546 → three thousand five hundred and forty-six |

| 不确切数量           | 含义         |
| -------------------- | ------------ |
| hundreds of          | 数百的       |
| thousands of         | 数以千计的   |
| millions of          | 数以百万计的 |
| tens of thousands of | 数以万计的   |

# 序数词

| 序数词      | 缩写 | 中文   | 规则        |
| ----------- | ---- | ------ | ----------- |
| first       | 1st  | 第一   | 不规则      |
| second      | 2nd  | 第二   | 不规则      |
| third       | 3rd  | 第三   | 不规则      |
| fourth      | 4th  | 第四   | 加 -th      |
| fifth       | 5th  | 第五   | ve → f + th |
| sixth       | 6th  | 第六   | 加 -th      |
| seventh     | 7th  | 第七   | 加 -th      |
| eighth      | 8th  | 第八   | 加 -h       |
| ninth       | 9th  | 第九   | 去 e 加 -th |
| tenth       | 10th | 第十   | 加 -th      |
| eleventh    | 11th | 第十一 | 加 -th      |
| twelfth     | 12th | 第十二 | ve → f + th |
| thirteenth  | 13th | 第十三 | 加 -th      |
| fourteenth  | 14th | 第十四 | 加 -th      |
| fifteenth   | 15th | 第十五 | 加 -th      |
| sixteenth   | 16th | 第十六 | 加 -th      |
| seventeenth | 17th | 第十七 | 加 -th      |
| eighteenth  | 18th | 第十八 | 加 -th      |
| nineteenth  | 19th | 第十九 | 加 -th      |

| 规则 | 说明 | 例子 |
| -------- | -------------- | ---------------------------------------- |
| 整十位数 | -y → -ie + th  | twenty → twentieth, thirty → thirtieth   |
| 几十几   | 只变个位       | twenty-second (22nd), fifty-sixth (56th) |
| 含百千   | 最后部分变序数 | one hundred and first (101st)            |

# 数词的应用

| 应用 | 规则 | 例子 |
| -------- | ------------------------------------ | --------------------------------------------------------- |
| 分数     | 分子基数 + 分母序数; 分子>1 分母加 s | 1/3 → one third, 3/5 → three fifths                       |
| 分数特例 | 1/2、1/4 有专用词                    | 1/2 → a half, 1/4 → a quarter                             |
| 带分数   | 整数 + and + 分数                    | 2 1/3 → two and one third                                 |
| 小数     | 逐位读, 小数点读 point               | 1.34 → one point three four                               |
| 百分数   | 数字 + percent                       | 25% → twenty-five percent                                 |
| 时间     | 半点前 past, 半点后 to               | 7:15 → a quarter past seven, 7:50 → ten to eight          |
| 日期英式 | 日 + 月 + 年                         | 12 December 2020 → the twelfth of December, twenty twenty |
| 日期美式 | 月 + 日 + 年                         | December 12, 2020 → December the twelfth, twenty twenty   |
| 长宽高   | 数字 + 单位 + adj / in + 名词        | 1000 meters long / 1000 meters in length                  |
| 温度     | 数字 + degrees + 单位                | 37°C → 37 degrees Celsius                                 |
| 倍数(1)  | 倍数 + the + 计量 + of               | three times the size of                                   |
| 倍数(2)  | 倍数 + as + adj + as                 | twice as many carrots as                                  |
| 倍数(3)  | 倍数 + 比较级 + than                 | three times faster than                                   |
