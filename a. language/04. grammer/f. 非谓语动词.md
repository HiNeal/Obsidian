# 基础知识

```plaintext
                         +------------------+
                     +-->|   动词不定式     |  to v / v (省略to) 
                     |   +------------------+
                     |
                     |   +------------------+
                     |-->|     动名词       |  v-ing 
+------------+       |   +------------------+
| 非谓语动词 |------>|
+------------+       |   +------------------+
（非限定动词）       |-->|    现在分词      |  v-ing
                     |   +------------------+
                     |
                     |   +------------------+
                     +-->|    过去分词      |  v-ed-en
                         +------------------+

谓语动词：配合助动词具备表达动作的时间、状态、语气的能力;
非谓语动词：失去了表达动作的时间、状态和语气的能力, 但可充当除了谓语以外的所有句子成分,从而达到避免或简化从句的效果;

一个简单句有且只能有一个谓语动词, 其他动词都需要以非谓语动词的形式出现;
```

# 动词不定式

定义：不受时间/人称等限制的动词形式称之为不定式;
形式：to + 动词原形（完全不定式）或 直接动词原形（裸不定式）;

| 句子成分   | 例子                                                    |
| ------ | ----------------------------------------------------- |
| 主语<br> | To eat a carrot every day is good for the rabbit.<br> |
| 宾语     | The rabbit likes to eat carrots.                      |
| 宾语补语   | The rabbit expected the wolf to eat a carrot.         |
| 主语补语   | The rabbit's dream is to eat every kind of carrot.    |
| 定语     | The rabbit has a lot of carrots to eat.               |
| 状语     | I was surprised to get a thumbs up.                   |

特殊动词 see、find、watch、have、make、let 用裸不定式做宾语补语, 需要省略 to：

| 例子 | 说明 |
| ------------------------------------- | ---------------------- |
| I saw the rabbit eat a carrot.        | see + 宾语 + 裸不定式  |
| Carrots make the rabbit feel happy.   | make + 宾语 + 裸不定式 |
| The wolf helped the rabbit (to) grow. | help 后 to 可省可不省  |

不定式与状态的结合：

| 状态 | 例子 | 中文 |
| -------- | ---------------------------------------------------- | ---------------------------------------- |
| 进行     | The rabbit seemed to be eating a carrot.             | 这兔子之前似乎在吃一根胡萝卜（的过程中） |
| 完成     | The rabbit will appear to have eaten a carrot.       | 这兔子之后会看起来像是吃过了一根胡萝卜   |
| 完成进行 | The rabbit will appear to have been eating a carrot. |                                          |

# 动名词

定义：把动词变成具有名词功能的形式称之为动名词;
形式：v-ing 转化为名词来用;
只能接动名词作宾语的动词：avoid、advise、consider、escape、mind、practice、enjoy、insist on、give up、feel like、put off;

| 句子成分 | 例子 |
| -------- | ------------------------------------------------------- |
| 主语     | Eating carrots is healthy for the rabbit.               |
| 表语     | The rabbit's hobby is growing carrots.                  |
| 定语     | A sleeping pill                                         |
| 动词宾语 | The rabbit enjoys eating carrots.                       |
| 介词宾语 | The rabbit is fond of eating carrots.                   |
| 介词宾语 | The rabbit is looking forward to seeing the wolf again. |

不定式 vs 动名词作宾语的区别：

| 结构 | 含义 | 例子 |
| ------------ | ---------------------- | ------------------------------------------- |
| stop to do   | 停下手中事去做另一件事 | The rabbit stopped to eat a carrot.         |
| stop doing   | 停止正在做的事         | The rabbit stopped eating a carrot.         |
| forget to do | 忘记要去做（还没做）   | The wolf forgot to invite the rabbit.       |
| forget doing | 忘记做过（已经做了）   | The rabbit forgot accepting the invitation. |

# 现在分词

现在分词做**非谓语动词**时没有时间属性, ⚠️ 现在分词 ≠ 现在时间, 应理解为现在分词 ≈ 形容词。

| 句子成分 | 例子 |
| ------------ | -------------------------------------------------- |
| 定语         | A talking rabbit.                                  |
| 表语         | The story is interesting.                          |
| 宾补         | The wolf saw the rabbit eating a carrot.           |
| 状语（时间） | Hearing the news, the rabbit became excited.       |
| 状语（原因） | Not knowing what to eat, the rabbit skipped lunch. |

现在分词 vs 动名词作定语：

| 例子 | 类型 | 含义 |
| ----------------- | --------------- | ------------------------- |
| a sleeping rabbit | 现在分词 → 状态 | a rabbit that is sleeping |
| a sleeping pill   | 动名词 → 用途   | a pill for sleeping       |

现在分词 vs 不定式作宾补：

| 例子 | 类型 | 含义 |
| --------------------------------------- | -------- | -------------------- |
| The wolf saw the rabbit eating a carrot | 现在分词 | 动作正在进行中       |
| The wolf saw the rabbit eat a carrot    | 不定式   | 动作全过程（已发生） |

# 过去分词

过去分词做**非谓语动词**时没有时间属性, ⚠️ 过去分词 ≠ 过去时间, 应理解为过去分词 ≈ 形容词, 表示**被动的状态**。

| 句子成分 | 例子 |
| ------------ | --------------------------------------------------------------- |
| 定语         | Minced carrot / an excited rabbit                               |
| 定语（后置） | The carrot cake eaten by the rabbit is delicious.               |
| 表语         | The rabbit is interested in growing carrots.                    |
| 宾补         | The rabbit found his carrot stolen.                             |
| 状语（地点） | Seen from the hill, the carrot field looks beautiful.           |
| 状语（原因） | Born in the rabbit family, the rabbit has been growing carrots. |
| 状语（条件） | Given another chance, the rabbit would go to the party.         |

现在分词（主动）vs 过去分词（被动）：

| 例子 | 中文 | 语态 |
| ------------------------- | ---------- | -- |
| The story is interesting. | 故事让人感兴趣    | 主动 |
| The rabbit is interested. | 兔子被引起兴趣    | 被动 |
| The rabbit was frightening. | 兔子令人害怕   | 主动 |
| The rabbit was frightened.  | 兔子感到害怕   | 被动 |

> 不要笼统认为过去分词修饰人、现在分词修饰物, 关键看主动还是被动。
