# 方式状语中置 (Heavy NP Shift)

方式状语常规位置在句尾, 但宾语较长而状语较短时, 状语可以插到动词和宾语之间, 让长宾语落在句末 (重成分后置, end-weight principle)。

| 类型 | 例子 | 说明 |
| --- | --- | --- |
| 常规 | portray the level of risk **with honesty** | 状语在句尾 |
| 中置 | portray **with honesty** the level of risk | `with honesty` 仍修饰 portray, 不修饰 risk |
| 限制 | portray it **with honesty** | 宾语是代词时不能前移, 不说 ~~portray with honesty it~~ |

- 语义不变, 文体偏书面, 学术文章常见。
- 读句子时先把 `with + 名词` 整体跳过, 再找真正的宾语。
- 类似: `handle with care the fragile items` = handle the fragile items carefully

# 省略 if 的虚拟倒装 (Were it not for)

虚拟条件句省略 `if`, 把 `were / had / should` 提到主语前, 构成部分倒装; 书面语、学术文章常见。

| 还原形式 | 倒装形式 | 说明 |
| --- | --- | --- |
| if it were not for ... | **Were it not for** ... | 要不是 ..., (与现在事实相反) |
| if it had not been for ... | **Had it not been for** ... | 要不是当初 ..., (与过去事实相反) |
| if + 主语 + should + v | **Should** + 主语 + v | 万一 ... |

- 例: The manuscript would attract little attention **were it not for the fact that** the drawings hint at esoteric knowledge.
- 结构: 主句 (`would` + v) + 倒装条件句; `the fact that` 后面是同位语从句。
- 读法: 先把 `were it not for the fact that` 当成"要不是"的标记, 读完从句内容再回头接主句。
- 条件句也可以前置: `Were it not for ..., the manuscript would attract little attention.`
- 相关: 虚拟语气见 `e. 语气.md`, 倒装见 `u. 倒装句.md`。

# ever 构词用法 (ever- / -ever)

`ever` 核心意象为"始终、永远、在任何时候" (全时间、无例外)。与其他词组合时, 放词首偏向时间轴上的"一直、不断", 放词尾偏向范围上的"无论、任何"或永久。

| 位置与类型 | 例子 | 说明 |
| --- | --- | --- |
| 词首 `ever-` (永恒不变) | **ever**green, **ever**lasting, **ever**more | 常青的、永恒的、永远 |
| 词首 `ever-` + 分词/形容词 | **ever**-changing, **ever**-growing, **ever**-present | 持续不断 / 日益…, 学术与新闻高频 |
| 词尾 `wh-` + `-ever` | what**ever**, who**ever**, which**ever**, where**ever**, when**ever**, how**ever** | 无论… / 任何…; 疑问句中表"究竟、到底" |
| 词尾 (时间 / 否定加强) | for**ever**, n**ever**, whatso**ever** | 永远; 从不 (`ne-` + `ever`); 丝毫 (加强否定, 如 *no doubt whatsoever*) |

- 记忆: `ever` 放前面是"一直、不断", 放后面是"无论、任何"。
- 亲戚词: `every` (来自 `ever` + `each`, 毫无例外的每一个); `nevertheless` (`never` + `the` + `less`, 从不因此减弱 → 尽管如此)。
- 相关: 构词见 `t. 构词法.md`, 让步状语从句见 `h. 从句.md`。
