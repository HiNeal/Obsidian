# 基础知识

限定词 = 限定讨论/描述范围的词。

> this carrot, my carrot, every carrot, many carrots, two carrots, the second carrot

限定词不归属于国内传统语法的某一特定词类, 而是从功能角度对某些词进行的归类。

# 哪些词可以充当限定词

| **词类** | **例子** |
| ---------- | ------------------------ |
| 冠词       | a, an, the               |
| 名词所有格 | the rabbit's, the wolf's |
| 物主代词   | my, your, his, her       |
| 指示代词   | this, that, these, those |
| 疑问代词   | whose, which             |
| 关系代词   | whose, which             |
| 不定代词   | some, many, each, any    |
| 量词       | a lot of, plenty of      |
| 基数词     | one, two, three          |
| 序数词     | first, second, third     |

# 限定词的顺序

限定词分为三个位次：

| 位次 | 包含 | 例子 |
| ---------- | ---------------------------- | --------------- |
| 前位限定词 | 某些不定代词、倍数词、分数词 | half my carrots |
| 中位限定词 | 冠词、物主代词、某些不定代词 | her last carrot |
| 后位限定词 | 基数词、序数词、量词         | all ten carrots |


⚠️ 常见错误

中位限定词不能叠用：

- ❌ my that carrot
- ✅ that carrot of mine

# 冠词
## 冠词分类

| 冠词   | 类型     | 功能          |
| ------ | -------- | ------------- |
| a / an | 不定冠词 | 泛指          |
| the    | 定冠词   | 特指          |
| ∅      | 零冠词   | 泛指复数/概念 |

## 不定冠词 a / an

发音规则：看发音（音素）, 不是看字母

| 规则   | 条件         | 正确                                           | 错误             |
| ------ | ------------ | ---------------------------------------------- | ---------------- |
| **a**  | 辅音音素开头 | a rabbit, a **university**（/juː/ = 辅音 /j/） | ❌ an university |
| **an** | 元音音素开头 | an apple, an **hour**（/aʊ/ = 元音, h 不发音） | ❌ a hour        |

用法总览

| 用法 | 说明 | 例子 |
| --------------- | ------------------------------- | ------------------------------------------ |
| 泛指某一个人/物 | 不特指, 不知道/不强调具体是哪个 | I saw **a** rabbit.                        |
| 泛指某一类人/物 | 表示整个类别                    | **A** rabbit is smarter than **a** wolf.   |
| 第一次提到      | 首次提及 → 算泛指               | I saw **a** rabbit.（后半句就要用 the 了） |
| 表示数字 1      | 相当于 one                      | I gave you **a** hundred carrots.          |
| 表示"每"        | 相当于 every/per                | I eat 10 carrots **a** day.                |
| 固定表达        | 不能替换或省略                  | have **a** good time, as **a** result      |

**⚠️ 泛指歧义**

> **A** rabbit is smart. → 泛指"兔子聪明"？还是"某一只兔子聪明"？**看语境。**

对比三句的歧义程度：

| 句子                             | 可理解为泛指？  | 可理解为某一只？  |
| -------------------------------- | :-------------: | :---------------: |
| A rabbit is eating a carrot.     | ❌ 明显是某一只 | ✅                |
| A rabbit is smart.               | ✅ 可能是泛指   | ✅ 也可能是某一只 |
| A rabbit is smarter than a wolf. | ✅ 大概率泛指   | ⚠️ 也有歧义       |

> **最佳泛指方式：零冠词复数 → Rabbits are smart.**

**影响主谓一致**

> **a** teacher and video creator → 一个人（兼职）
> **a** teacher and **a** video creator → 两个人

## 定冠词 the

发音规则：看发音（音素）, 不是看字母

| 发音 | 条件 | 例子 |
| ------ | ---------- | ------------------------------ |
| **ðə** | 辅音音素前 | the rabbit, the **university** |
| **ði** | 元音音素前 | the apple, the **hour**        |

用法总览

| 用法 | 说明 | 例子 |
| -------------- | ---------------------- | --------------------------------------------- |
| 再次提到       | 前文提过的, 双方都知道 | I saw a rabbit. **The** rabbit ran fast.      |
| 对话双方都知道 | 无需多说, 心知肚明     | Please give me **the** carrot.                |
| 序数词前       | 序数已确定唯一         | **the** first rabbit                          |
| 最高级前       | 最高级已确定唯一       | **the** biggest carrot                        |
| 独一无二       | 宇宙中只有一个         | **the** sun, **the** moon, **the** Great Wall |
| 西洋古典乐器   | 泛指弹奏该乐器这一行为 | play **the** piano, play **the** violin       |
| the + 形容词   | 表示一类人             | **the** rich, **the** poor                    |
| 固定表达       | 不能省略 the           | all **the** time, by **the** way              |

**第一次 vs 第二次**

> I saw **a** rabbit. **The** rabbit ran fast.
> 前半句 → a（第一次, 泛指） → 后半句 → the（第二次, 特指同一只）

> ❌ I saw a rabbit. **A** rabbit ran fast. → 英语母语人士会迷惑：有两只兔子？

**对话特指 vs 对话泛指**

> Please give me **the** carrot. → 特指：就要那一根, 别的不要
> Please give me **a** carrot. → 泛指：随便拿一根就行

**乐器的特殊情况**

> play **the** piano → 泛指"弹钢琴"这一艺术行为（不是弹某架特定的琴）
> play **a** piano → 弹一架钢琴（某架具体的琴）

⚠️ 只有**西洋古典乐器**（piano, guitar, violin, flute 等）加 the。非西洋乐器（如二胡）不加：play erhu

**the 也可以泛指（但不推荐）**

> **The** computer has changed our way of life. → 泛指电脑这一类工具
> ⚠️ 容易被误解为特指某一台电脑。**推荐零冠词复数：Computers have changed our way of life.**

## 零冠词 ∅

用法总览

| 用法 | 说明 | 例子 |
| ------------------- | -------------------------- | -------------------------------- |
| 复数泛指            | 最推荐、最不歧义的泛指方式 | Rabbits are smart.               |
| 不可数名词          | 当作不能加 s 的复数        | Water is important.              |
| 抽象概念            | 脑中形成的观念/概念        | Summer is hot. I like geography. |
| 季节/星期/月份/节日 | 表示概念时                 | in spring, on Monday             |
| 球类运动            | 泛指这项运动               | play football                    |
| 学科                | 泛指学科概念               | I like geography.                |
| 专有名词            | 人名/地名, 不需要冠词界定  | Papa Rabbit, China               |
| 固定表达            | 零冠词固定搭配             | face to face, out of question    |

为什么"最推荐零冠词复数"？

| 方式 | 例子 | 歧义风险 |
| ------------ | ---------------------------------- | :---------------------: |
| 不定冠词泛指 | A rabbit is smart.                 | ⚠️ 高（可理解为某一只） |
| 定冠词泛指   | The computer has changed our life. | ⚠️ 中（可理解为某一台） |
| 零冠词复数   | Rabbits are smart.                 | ✅ 低                   |

⚠️ 零冠词 vs 定冠词 — 意思完全相反

| 零冠词                          | 定冠词                              |
| ------------------------------- | ----------------------------------- |
| out of **question**（毫无疑问） | out of **the** question（不可能）   |
| go to **school**（上学）        | go to **the** school（去那所学校）  |
| in **hospital**（住院）         | in **the** hospital（在医院大楼里） |

## 总结

| 冠词 | 核心功能             | 最推荐场景                         |
| ---- | -------------------- | ---------------------------------- |
| a/an | 泛指某一类中的"一个" | 第一次引入话题、表示"一个"         |
| the  | 特指双方都知道的     | 再次提到、序数词、最高级、独一无二 |
| ∅    | 泛指复数/概念        | 最准确、最不歧义的泛指             |
