# 祈使语气

构成：用第二人称一般现在时, 去掉"you", 动词用原形。

| 原句                 | 祈使句          |
| -------------------- | --------------- |
| (You) eat the carrot | Eat the carrot! |
| (You) don't eat it   | Don't eat it!   |
| (You) be quiet       | Be quiet!       |

# 虚拟语气

## 1. 与事实相反的假设

| 虚拟时间       | if 条件句谓语        | 主句谓语                             |
| -------------- | -------------------- | ------------------------------------ |
| 和现在事实相反 | v-ed / were          | would/should/might/could + v         |
| 和过去事实相反 | had v-ed-en          | would/should/might/could + have v-ed-en |
| 和未来事实相反 | should + v / were to | would/should/might/could + v         |

If I saw the rabbit now, I would bite him.  // 如果我现在看到兔子, 我就咬他。

If I had seen the rabbit, I would have bitten him.  // 如果我之前见过那只兔子, 我就咬他。

If I should see the rabbit tomorrow, I would bite him.  // 如果我明天看到那只兔子, 我就咬他。

## 2. 表达愿望、请求、建议、命令

wish、would rather、demand、suggest、insist、order

| 愿望时间     | wish 子句结构                |
| ------------ | ---------------------------- |
| 对现在的愿望 | wish + v-ed / were           |
| 对过去的愿望 | wish + had + v-ed-en         |
| 对将来的愿望 | wish + would/might/could + v |

I wish that I were a rabbit  // 我希望我是只兔子

I wish that I had eaten the carrot  // 我希望我吃了那胡萝卜

I wish that I could eat the carrot  // 我希望我能吃到那胡萝卜
