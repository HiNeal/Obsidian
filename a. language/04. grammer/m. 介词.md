# 介词基础

> 凡虚字用以连实字相关之意者, 曰介字。介字云者, 犹为实字之介绍耳。
> —— 马建忠《马氏文通》

**定义与词源**

* **词源拆解**：`Preposition` = `pre-`（在前） + `position`（位置） → 放置在前面的词。
* **本质定义**：通常放在名词、代词等之前, 用来增添空间、时间和逻辑关系等附加信息。
* **核心特征**：介词**不能单独做句子成分**, 必须与其后的介词宾语结合形成介词短语, 才能表达完整意思。

**核心学习方法：空间本意 → 引申义**, 每个介词通常都有根源的**空间含义**, 在其基础之上自然引申出时间与逻辑关系：

# 构成形式

| **类型**                       | **说明**                     | **例子**                                                                                                   | **结构示例**                                                           |
| ---------------------------- | -------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 简单介词                         | 单个词                        | in, on, at, to, with, for                                                                                | —                                                                  |
| <br><br><br><br><br>**短语介词** | <br><br><br><br><br>短语充当介词 | by way of<br><br>at the end of<br><br>along with<br><br>because of<br><br>previous to<br><br>relative to | 介+名+介<br><br>介+the+名+介<br><br>介+介<br><br>连+介<br><br>形+介<br><br>形+介 |

短语介词 ≠ 介词短语。短语介词相当于介词(意思不完整); 介词短语意思已完整, 往往相当于副词。

# 单介词

以空间本意为物理核心, 自然引申至时间维度与抽象逻辑关系。单个单词构成的简单介词、合成介词与分词介词, 按照词条字符长度由短到长排列：

## at

空间本意为“精准聚焦的点”, 引申为时间上的明确时刻、从事特定活动的状态、靶心对象以及标尺上的数值比率：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 空间 | 在…处; 在…地点 | **at** the corner<br><br>**at** the station |
| 时间 | 在（具体时刻/钟点） | **at** 6 o'clock<br><br>**at** noon<br><br>**at** dawn |
| 状态 | 在…中; 处于…状态 | **at** work<br><br>**at** dinner |
| 对象 | 对着; 冲着 | laugh **at** the joke |
| 数值 | 以（某价格/速度/比率） | **at** a high price<br><br>**at** a fast rate |

## in

空间本意为“在容器或封闭空间内部”, 引申为包含较长时段的时间范围、身处的处境状态、沉浸的交际语言媒介、统辖的规模容量以及局部的限定程度：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 空间 | 在…里面; 在…内部 | **in** the house<br><br>**in** the park |
| 时间 | 在（某年/月/时段）; 在…之内 | **in** 2030 |
| 状态 | 处于…状态/过程中 | **in** progress<br><br>**in** a dilemma |
| 方式 | 用（语言/方式） | talk **in** English |
| 范围 | 以…规模/数量 | fly **in** vast numbers |
| 程度 | 部分地 | **in part** because the designers aren't |

## on

空间本意为“在平面上紧密接触与承载支撑”, 引申为具体某天的时间、讨论依托的专门话题、身心依赖的维持状态以及信息传播的设备媒介：

| -------- | ---- | ---- |

| 状态 | 处于…状态; 依赖于 | **on** a diet<br><br>**on** drugs |
| 方式 | 通过（设备/媒介） | talk **on** the phone |
| 话题 | 关于; 有关 | advice **on** learning English |

## of

## to

空间本意为“朝向终点并最终抵达”, 在逻辑关系中引申为终点时刻、动作信息的接收对象、属性所归属的体系以及并置投射比对的比较基准：

| 从属 | 原产于; 对…而言 | a large evergreen tree native **to** Southeast Asia |
| 比较 | 与…相似<br><br>与…相比; 比作<br><br>与…相比<br><br>与…相当; 可相比<br><br>等同于; 相当于<br><br>优于; 胜过<br><br>不如; 次于<br><br>与…相比; 相对于<br><br>与…成比例的<br><br>与…相反 | The pattern is **similar to** that observed in neighbouring countries<br><br>Man's life is often **compared to** a candle<br><br>**Compared with** private cars, public transport produces fewer emissions<br><br>The figure is **comparable to** that of the previous year<br><br>The reduction is **equivalent to** removing thousands of cars from the roads<br><br>Public transport is often **superior to** private cars in terms of efficiency<br><br>Recycled materials are not necessarily **inferior to** new materials<br><br>more dominant laughs **relative to** the low-status individuals<br><br>The increase in funding should be **proportionate to** the growth in student numbers<br><br>**contrary to** popular perception |

# 双介词

由两个单词组合而成的短语介词（通常为「介/副/形 + 介」结构）, 整体相当于一个介词起连接与修饰作用。按照短语字符长度由短到长排列：

| -------- | ---- | ---- |

| 归属 | 取决于; 由…负责 | it is **up to** you to decide |

| -------- | ---- | ---- |

复合介词, 用于转换话题或将叙述焦点聚焦在某一人或特定事物上：

| -------- | ---- | ---- |

# 三介词

由三个或以上单词构成的多词短语介词（大多遵循「介 + 名 + 介」的经典框架结构）, 广泛用于学术与论述文体。按照短语字符长度由短到长排列：

## on top of

空间本意为“位于某一物体的最高表面”, 引申为在既有负担或收获之上新增重叠以及彻底掌控局面：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 空间 | 在…之上 | books piled **on top of** each other |
| 附加 | 除…之外还; 叠加 | extra expenses **on top of** tuition fees |

## by way of

空间本意为“取道路经某地”, 引申为以某种形式、作为某种解释或说明：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 空间 | 途经; 经由 | travel to Paris **by way of** London |
| 方式 | 作为…的方式/形式 | offered an apology **by way of** explanation |

## in view of

空间本意为“处于视线所及范围”, 引申为将某些客观事实作为决策和判断的立足依据：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 原因 | 鉴于; 考虑到 | cancelled the trip **in view of** severe weather |

## in case of

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 条件 | 万一; 如果发生 | sound the alarm **in case of** fire |

## in need of

状态复合介词, 表达处于缺乏某种必要资源、支持或修缮的客观状态：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 状态 | 需要; 处于…需求中 | historic buildings **in need of** urgent repair |

## as well as

复合介词结构, 在同类语义之间实现同等并置与补充延伸：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 附加 | 除…之外还; 连同 | provides mentoring **as well as** financial aid |

## in front of

空间本意为“在…的正前方/面前”：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 空间 | 在…前面 | standing **in front of** the wolf |

## in spite of

短语介词, 相当于 despite, 表示不顾阻碍或恶劣事实依然发生：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 让步 | 尽管; 虽然 | succeeded **in spite of** the difficulties |

## in terms of

学术与议论文高频逻辑复合介词, 用于将论述限定在特定的维度、指标或切入点上：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 范围 | 从…角度而言; 在…方面 | highly effective **in terms of** energy savings |

## in light of

空间本意为“在光线照亮之下”, 引申为借由最新披露的信息、事实作为思考依据：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 原因 | 鉴于; 考虑到; 根据 | reassessed the strategy **in light of** recent events |

## in place of

空间本意为“占据原先的位置”, 引申为功能、人员或物品的更替与取代：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 替换 | 代替; 取代 | adopt clean technology **in place of** fossil fuels |

## in favor of

立场与态度复合介词, 表达倾心支持某项决议或促成有利于某方的局面：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 立场 | 赞成; 支持; 有利于 | voted overwhelmingly **in favor of** the motion |

## by means of

方式复合介词, 指通过借助特定的科学手段、机械工具或策略达成目标：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 方式 | 依靠; 凭借; 通过…手段 | ascended the cliff **by means of** ropes and anchors |

## on behalf of

代表与立场复合介词, 指代某人行使权力、发声或为维护某一集体的权益：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 代表 | 代表; 为了…的利益 | accepted the award **on behalf of** the team |

## by virtue of

书面逻辑复合介词, 指凭借某种特权、法定地位、优越特质而享有成果：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 原因 | 凭借; 依靠; 由于 | gained admission **by virtue of** academic excellence |

## in search of

目的复合介词, 表达朝着寻找特定生存资源、证据或答案的方向持续探寻：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 目的 | 寻找; 搜寻 | migrated north **in search of** fresh pastures |

## on account of

较正式的原因复合介词, 指出于明确记录在案或无可辩驳的因果依据：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 原因 | 因为; 由于 | match suspended **on account of** severe pitch flooding |

## in the face of

空间本意为“面对面遭遇”, 引申为面临严峻阻碍或危险时不退缩：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 让步 | 面对; 面临; 不顾 | **In the face of** appalling obstruction from the sugar industry |

## over and above

空间高出上方, 引申为在既有事物之外另有更多附加：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 附加 | 除…之外 | **over and above** low cost |

## in addition to

逻辑递进与新增复合介词, 在既有清单或事实基础上堆叠更多内容：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 附加 | 除…之外还 | acquired fluency in Spanish **in addition to** French |

## with regard to

正式学术与公文复合介词, 用于引出关涉的主题或明确评论范围：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 话题 | 关于; 至于 | raised concerns **with regard to** consumer safety |

## in contrast to

比较与对立复合介词, 将两者并置以凸显鲜明的性质或数据差异：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 比较 | 与…形成鲜明对比 | **in contrast to** urban schools, rural facilities lagged behind |

## with respect to

较严肃的正式公文复合介词, 将分析目光严格聚焦于某一特定事项或条款：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 话题 | 关于; 就…而言 | revised guidelines **with respect to** privacy protection |

## for the sake of

目的与动机复合介词, 指出于对某人利益的关照、某种信念的坚持或纯粹为了达成某目标：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 目的 | 为了…的利益; 看在…份上 | relocated to the countryside **for the sake of** health |

## at the expense of

代价与牺牲复合介词, 表达在取得某种利益的同时所牺牲、损耗的代价：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 代价 | 以…为代价 | rapid industrial expansion **at the expense of** clean air |

## in comparison with

对比复合介词, 将两个或多个对象置于同等尺度下进行长短高低的权衡：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 比较 | 与…相比 | modest gains **in comparison with** projected targets |

## in accordance with

依据与契合复合介词, 表明行为或方案严格遵从法律条文、既定规则或客观惯例：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 依据 | 按照; 依据; 与…一致 | audited **in accordance with** international accounting standards |

## not least because of

复合介词表达, 强调某原因是诸多原因中最重要、最不容忽视的一个：

| 表示关系 | 释义 | 意群 |
| -------- | ---- | ---- |
| 原因 | 尤其是因为 | **not least because of** the critical articles |

# 介词短语

介词 + 介词宾语 = 介词短语, 可充当各种句子成分：

| **成分** | **例子** |
| ------- | -------------------------------------------- |
| 主语 | **Between 10 and 11** is a good time for me. |
| 表语 | The meeting is **at 2 o'clock**. |
| 定语 | This is the key **to the house**. |
| 宾补 | I found the carrot **in good condition**. |
| 状语（最常见） | The rabbit ate a carrot **at noon**. |


# 介词动词

由**动词 + 介词**（如 *to, on, with, of, at*）构成的固定组合, 介词后必须紧跟宾语, 整体表达特定的动作方向或引申义。

**与短语动词的核心区别**：介词动词后面的成分是**纯介词**, 代词宾语**绝不可**插入动词与介词中间。

> ✅ depend on **them** / ❌ depend them on
> ✅ comply with **it** / ❌ comply it with
