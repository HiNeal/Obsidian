# 定义

叹词 = 负责表达情感的声音、单词、词组

不仅包括单音节感叹词（啊、哦、嘿）, 也包括主要用于表达情感的名词、动词等转化而来的词或短语。

# 常见感叹词

打招呼/问候

| **叹词** | **含义** | **例子** |
| --------------- | -------- | ----------------------- |
| Hello! / Hi!    | 你好！   | Hello! How are you?     |
| Hey!            | 嘿！     | Hey! Long time no see!  |
| Goodbye! / Bye! | 再见！   | Goodbye! See you later! |

惊讶

| **叹词** | **含义** | **例子** |
| ------------- | -------- | ---------------------------- |
| Oh!           | 哦！啊！ | Oh! I didn't see you there.  |
| Wow!          | 哇！     | Wow! That carrot is huge!    |
| Gosh!         | 天哪！   | Gosh! It's amazing!          |
| Good heavens! | 天啊！   | Good heavens! What happened? |

喜悦/兴奋

| **叹词** | **含义** | **例子** |
| -------- | -------- | -------------------- |
| Yay!     | 耶！     | Yay! I got a carrot! |
| Hurray!  | 万岁！   | Hurray! We won!      |
| Woohoo!  | 喔吼！   | Woohoo!              |

痛苦/遗憾

| **叹词** | **含义** | **例子** |
| -------- | -------- | ------------------------- |
| Ouch!    | 哎哟！   | Ouch! That hurts!         |
| Alas!    | 唉！     | Alas! The carrot is gone. |
| Oh no!   | 哦不！   | Oh no! I dropped it.      |

愤怒/不满

| **叹词** | **例子** |
| -------- | ---------------------------- |
| Hey!     | Hey! That's mine!            |
| Ugh!     | Ugh! This carrot tastes bad. |
| What!    | What! You ate it all?        |

引起注意/停顿

| **叹词** | **例子** |
| ------------- | -------------------------------- |
| Well...       | Well, I'm not sure.              |
| Uh... / Um... | Um, let me think...              |
| Ahem          | Ahem, may I have your attention? |

赞同/认可

| **叹词** | **例子** |
| --------- | ------------------ |
| Yes!      | Yes! That's right! |
| Right     | Right, I agree.    |
| OK / Okay | OK, let's do it.   |
