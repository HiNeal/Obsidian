# 特殊疑问句

## 核心法则

| 提问方向                                | 标准公式                                                    | 典型例句                                                                                          |
| :---------------------------------- | :------------------------------------------------------ | :-------------------------------------------------------------------------------------------- |
| **问主语**                             | 疑问词 (名词) + 动词 + 其他?                                     | What caused the fire?<br>Which places are recommended?                                        |
| **问其他（be 动词）**<br>*(系表 / 进行 / 被动)*  | 疑问词 + (限定疑问词可带名词 + 定语) + **be** + 主语 + 状态/doing/done?   | Why **is** the park closed?<br>What equipment **is** required?<br>What is it used **for**?    |
| **问其他（助动词 / 情态动词）**<br>*(实义动词主动动作)* | 疑问词 + (限定疑问词可带名词 + 定语) + **助动词/情态动词** + 主语 + 动词原形/done? | What **does** he suggest?<br>What equipment **does** he need?<br>How **can** we improve this? |

> 在复杂疑问句中 **`be 动词` / `助动词`** 可以作为划分短语的最佳指示牌

## 疑问词搭配对照表

- **搭配 be 系列**：提问**静态性质/定义**（系表）、**正在进行**（`be doing`）或**被动语态**（`be done`）, 句末常带介词悬空（如 *for / about*）。
- **搭配 助动词 / 情态动词系列**：句子谓语为**实义动词**, 必须借用工具词（`do / have / can / will` 等）提到主语前。

| 疑问词（含词性）                  | 搭配 `be`（状态 / 进行 / 被动）                                                    | 搭配 `助动词 / 情态动词`（实义动词）                                                          |
| :------------------------ | :----------------------------------------------------------------------- | :----------------------------------------------------------------------------- |
| **Why**<br>adv.           | Why **is** the method so popular?<br>Why **is** the park closed today?   | Why **does** the manager refuse it?<br>Why **should** the speaker mention X?   |
| **How**<br>adv.           | How **is** the food prepared?<br>How long **is** the exhibition?         | How **does** the machine work?<br>How often **should** I clean it?             |
| **Who(m)**<br>pron.       | Who **is** responsible for this?<br>Who **is** invited to the event?     | Who(m) **does** the director trust?<br>Who **can** we contact?                 |
| **When**<br>adv.          | When **is** the deadline?<br>When **was** the interview scheduled?       | When **does** the train leave?<br>When **will** the course start?              |
| **Where**<br>adv.         | Where **is** the library located?<br>Where **is** the reception desk?    | Where **does** the bus stop?<br>Where **have** they gone?                      |
| **What**<br>pron. / det.  | What **is** required for the job?<br>What **is** this tool used **for**? | What **does** the speaker suggest?<br>What **have** you decided on?            |
| **Which**<br>pron. / det. | Which place **is** recommended?<br>Which facility **is** available?      | Which option **does** the man prefer?<br>Which method **should** the team use? |
| **Whose**<br>pron. / det. | Whose idea **is** it?<br>Whose project **was** approved?                 | Whose advice **does** the team follow?<br>Whose car **can** he borrow?         |
