- 助动词：用于帮助谓语动词表达的被动、可能性、义务性等;
- 谓语动词：配合助动词具备表达动作的时间、状态、语气的能力(一个简单句只能有一个谓语动词);
- 非谓语动词：失去了表达动作的时间、状态和语气的能力, 可充当除了谓语以外的所有句子成分,从而达到避免或简化从句效果;

# 约定

| 含义   | 缩写      | 作用                                            | 例子     |
| ---- | ------- | --------------------------------------------- | ------ |
| 原形   | v       | 谓语动词用于人称变位 / 不定式                              | eat    |
| 三单   | v-s     | 谓语动词用于人称变位                                    | eats   |
| 过去式  | v-ed    | 谓语动词用于时态变位                                    | ate    |
| 现在分词 | v-ing   | 谓语动词用于时态变位 / 非谓语动词表示主动 / 含义为正在 xxx 的形容词 / 动名词 | eating |
| 过去分词 | v-ed-en | 谓语动词用于时态变位 / 非谓语动词表示被动 / 含义为已经 xxx 的形容词       | eaten  |
动词是完全可以通过 v-ing / v-ed的形式转化成名词和形容词,从而去做各种句子成分的
