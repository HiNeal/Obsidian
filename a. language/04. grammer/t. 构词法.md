# 构词分类

| 方法   | 说明               | 例子                          |
| ---- | ---------------- | --------------------------- |
| 派生构词 | 词根加词缀（前缀/后缀）构成新词 | happy → unhappy / happiness |
| 合成构词 | 两个及以上词合在一起       | black + board → blackboard  |
| 混合构词 | 两个词各取一部分混合       | breakfast + lunch → brunch  |
| 截短构词 | 把长词截短            | advertisement → ad / advert |
| 缩写构词 | 取首字母缩写           | United Nations → UN         |

# 派生构词

派生构词 = 词根（root）+ 词缀（affix）。词根是单词的核心含义, 词缀附加在词根前后改变词义或词性。

举个例子：unhappiness = un-（前缀）+ happy（词根）+ -ness（后缀）

英语词汇主要有两大来源：
- **日耳曼语**：最基础、最日常的词汇。如 water（水）、hand（手）, 和德语同源
- **希腊语和拉丁语**：后来进入英语, 多为正式/学术词汇。大部分词缀来自希拉语

就像中文偏旁部首——"三点水"的字往往和水有关。掌握词根能大幅提升猜词能力。

**前缀（prefix）**放在词根前, 改变词义但不改变词性：

| 前缀 | 含义 | 例子 |
| ---- | ---------- | -------------------------- |
| un-  | 不、否定   | happy → unhappy            |
| re-  | 再次、重新 | write → rewrite            |
| pre- | 在…之前    | view → preview             |
| dis- | 不、否定   | agree → disagree           |
| mis- | 错误       | understand → misunderstand |

**后缀（suffix）**放在词根后, 改变词性：

| 后缀 | 转换 | 例子 |
| ----------- | ------------------- | ------------------- |
| -ness       | 形容词→名词         | happy → happiness   |
| -ly         | 形容词→副词         | quick → quickly     |
| -er         | 动词→名词（人/物）  | teach → teacher     |
| -tion/-sion | 动词→名词           | educate → education |
| -able/-ible | 动词→形容词         | read → readable     |
| -ful        | 名词→形容词         | beauty → beautiful  |
| -less       | 名词→形容词（否定） | hope → hopeless     |

**拼写衔接规则**：词根、前缀、后缀拼接时, 为了发音顺畅, 交界处常发生以下变化：

| 规则 | 说明 | 例子 |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 元音省略（elision）              | 词根/前缀末尾元音与后一词素开头元音相遇时, 为避免连续元音拗口, 省略前者末尾的元音                                                                                                      | oxy + ide → oxide（元音相遇, y 省略）; oxy + gen → oxygen（gen 辅音开头, y 保留）                       |
| 辅音同化（assimilation）         | 前缀末尾辅音会变成与词根首字母一致, 形成双写字母, 方便发音连贯。`01. base/prefix.md` 里 ad-/ac-/af-/ag-/al-/an-/ap-/ar-/as-/at- 等一系列变体, 本质都是同一个前缀因同化而产生的拼写变形 | in- + legal → illegal; ad- + cede → accede; syn- + logy → syllogy                                       |
| 连接元音（connecting vowel -o-） | 希腊语来源的词根组合时, 中间插入 -o- 便于发音, 即使词根本身不需要该元音。方向与元音省略相反, 是"插入"而非"省略"                                                                        | therm + o + meter → thermometer; cardi + o + logy → cardiology; electr + o + magnetic → electromagnetic |

# 合成构词

两个及以上的词合在一起构成新词, 复合名词最常见：

| 类型 | 例子 |
| ------------- | ----------------------------- |
| 名词 + 名词   | blackboard, haircut, sunshine |
| 形容词 + 名词 | blackbird, greenhouse         |
| 动词 + 名词   | pickpocket, breakfast         |
| 介词 + 名词   | afternoon, downtown           |

写法多样：连写（blackboard）、加连字符（mother-in-law）、分开写（high school）。

# 混合构词

两个词各取一部分拼成新词, 比合成更进一步：

| 词 A      | 词 B  | 混合词            |
| --------- | ----- | ----------------- |
| breakfast | lunch | brunch（早午餐）  |
| smoke     | fog   | smog（烟雾）      |
| motor     | hotel | motel（汽车旅馆） |

# 截短构词

把长词截去一部分：

| 方式 | 例子 |
| -------- | --------------------------- |
| 截去词尾 | advertisement → ad / advert |
| 截去词首 | hamburger → burger          |

# 缩写构词

取每个单词的首字母组成新词：

| 缩写 | 全称                  |
| ---- | --------------------- |
| UN   | United Nations        |
| VIP  | very important person |
| TV   | television            |
| CD   | compact disc          |
