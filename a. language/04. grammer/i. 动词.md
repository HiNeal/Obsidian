# 助动词

助动词与主动词搭配, 帮助表达时态、体、语态、否定或疑问等语法意义。情态助动词还表达能力、许可、可能、义务等含义。

| 助动词 | 用途 | 例子 |
| ---- | ---- | ---- |
| be | 构成进行时 | The rabbit is eating a carrot. |
| be | 构成被动语态 | The carrot was eaten by the rabbit. |
| do | 构成否定句或疑问句 | The rabbit does not like freeloaders. |
| have | 构成完成时 | The rabbit has eaten a carrot. |
| can | 表示能力 | I can kill a wolf. |
| must | 表示义务 | You must finish your homework. |

**used to** 表示过去经常发生、而现在已不再如此的习惯, 通常称为半助动词结构：

*The rabbit used to eat apples.*（这只兔子过去常吃苹果。）



# 谓语动词

谓语说明主语做什么、处于什么状态。谓语可以只有一个主动词, 也可以由助动词和主动词一起构成。谓语中的限定动词体现时态, 并在需要时与主语保持人称和数的一致。

## 系动词

系动词连接主语和表语, 表语说明主语的身份、性质或状态。

| 动词 | 类型 | 含义 | 例子 |
| ---- | ---- | ---- | ---- |
| be | 基本 | 是 | The rabbit is a teacher. |
| smell | 感官 | 闻起来 | The carrot smells nice. |
| look | 感官 | 看起来 | The rabbit looks cute. |
| sound | 感官 | 听起来 | That sounds great. |
| become | 变化 | 变得 | The rabbit became angry. |
| turn | 变化 | 变得 | The leaves turned yellow. |
| remain | 保持 | 仍然是 | The room remained empty. |

## 使役动词

使役动词表示使、让或安排某人做某事, 常见结构为“使役动词 + 宾语 + 宾语补足语”。不同使役动词后接的补足语形式不同。

| 动词 | 含义 | 宾语补足语形式 | 例子 |
| ---- | ---- | ---- | ---- |
| make | 迫使某人做 | 动词原形 | I make the wolf eat carrots. |
| make | 使某人/物处于某状态 | 形容词 | The carrot made the wolf full. |
| let | 允许某人做 | 动词原形 | I'll let the wolf eat some chocolate. |
| have | 安排某人做; 使某事被做 | 动词原形; 过去分词 | I had my car washed. |
| get | 说服或安排某人做 | to + 动词原形 | I'll get the wolf to clean the kitchen. |

## 动词形式

动词形式本身不等于时间。时间和体通常由谓语结构及上下文表达; 例如, 现在分词可以用于过去或将来的语境。

| 形式     | 标注           | see（规则） | write（不规则） | be         |
| ------ | ------------ | ------- | ---------- | ---------- |
| 原形     | v            | see     | write      | be         |
| 第三人称单数 | v-s          | sees    | writes     | is         |
| 过去式    | v-ed         | saw     | wrote      | was / were |
| 现在分词   | v-ing        | seeing  | writing    | being      |
| 过去分词   | v-ed-en  | seen    | written    | been       |

## 不规则动词变化规律

| 规律 | 动词原形 | 过去式 | 过去分词 |
| ---- | ---- | ---- | ---- |
| i→a→u 型 | begin, sing, swim | began, sang, swam | begun, sung, swum |
| e→o→en 型 | speak, freeze, choose | spoke, froze, chose | spoken, frozen, chosen |
| ow/aw→ew→wn/awn 型 | blow, grow, know, draw | blew, grew, knew, drew | blown, grown, known, drawn |
| 改为 -ought | bring, buy, fight, think | brought, bought, fought, thought | brought, bought, fought, thought |

# 非谓语动词

非谓语动词不能单独充当限定谓语, 但可以保留动词的部分特征, 并在句中充当主语、宾语、定语、状语或补语等成分。非谓语形式本身不标示人称和数, 其时间关系通常结合形式和上下文理解。

| 类型 | 形式与说明 |
| ---- | ---- |
| 不定式 | to + 动词原形; 裸不定式不带 to, 因此不定式不只指 to v |
| 动名词 | v-ing; 具有名词性, 可作主语、宾语等 |
| 现在分词 | v-ing; 可构成非谓语结构, 也可作形容词 |
| 过去分词 | 规则动词通常加 -ed; 不规则形式包括 -en 等; 可用于非谓语结构, 也可作形容词, 常带被动或完成含义 |

判别时要看动词在句中的功能, 不能只凭形式判断。例如, **-ing** 形式既可能出现在进行时谓语中, 也可能是非谓语动词。
