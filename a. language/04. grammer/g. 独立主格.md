
当从句主语和主句主语一致时, 可以省略主语, 并通过非谓语动词简化为简单句;
当从句主语和主句主语不一致时, 不可以省略逻辑主语(保留的逻辑主语称之为独立主格), 通过非谓语动词简化为简单句;

| 情况                               | 原句                                                      | 简化后                                           |
| ---------------------------------- | --------------------------------------------------------- | ------------------------------------------------ |
| 主语相同, 直接用过去分词简化       | Because the rabbit was invited, the rabbit decided to go. | Invited, the rabbit decided to go.               |
| 主语不同, 保留逻辑主语（独立主格） | Because the wolf invited him, the rabbit decided to go.   | The wolf inviting him, the rabbit decided to go. |

独立主格结构：

| 结构 | 说明 | 例子 |
| ------------------------------ | ----------------- | ---------------------------------------------------------------- |
| 名/代 + 不定式                 | 逻辑主语将要发生  | The rabbit to come, the wolf is overjoyed.                       |
| 名/代 + 现在分词               | 逻辑主语主动进行  | The wolf inviting him, the rabbit decided to go.                 |
| 名/代 + 过去分词               | 逻辑主语被动/完成 | The work finished, the rabbit went home.                         |
| 名/代 + 名词（省略 being）     |                   | Many animals went to the party, some of them rabbits and wolves. |
| 名/代 + 形容词（省略 being）   |                   | Many animals went, some of them happy.                           |
| 名/代 + 副词（省略 being）     |                   | The rabbit sat on the chair, head down.                          |
| 名/代 + 介词短语（省略 being） |                   | The rabbit came in, carrot in hand.                              |
| with + 名/代 + 过去分词        | with 复合结构     | With the work finished, the rabbit went home.                    |
| with + 名/代 + 介词短语        | with 复合结构     | With a carrot in his hand, the rabbit came in.                   |
| with 复合结构（后置）          | 伴随状语          | The rabbit came in, with a carrot in his hand.                   |
| 省略 with + 物主代词           | 退化为独立主格    | The rabbit came in, carrot in hand.                              |
