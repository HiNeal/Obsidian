# 核心概念

倒装句 = 为了强调某些信息而颠倒了原有语序的句式。英语倒装句主要有三大类：完全倒装、部分倒装、形式倒装。

| 类型       | 说明                                         |
| ---------- | -------------------------------------------- |
| 完全倒装句 | 谓语动词完全放在主语之前                     |
| 部分倒装句 | 只把助动词/情态动词提到主语之前              |
| 形式倒装句 | 谓语动词不提前, 只把强调内容提到句首（前置） |

# 完全倒装句

谓语动词整体提前到主语前。

| 触发条件 | 例子 |
| ------------------------------------------ | -------------------------------------------------------------------------------- |
| 地点副词句首（here / there）               | Here comes the bus. / There goes the last bus.                                   |
| 时间副词句首（now / then）                 | Now comes the wolf's turn.                                                       |
| 运动方向副词句首（in/out/up/down/away 等） | Up went the carrots into the air. / Down fell the apples. / Away ran the rabbit. |
| 介词短语句首                               | At the table sat a rabbit.                                                       |
| 表语 / 主语补语置于句首                    | Seated on the ground is a group of rabbits. / Such were the wolf's tricks.       |

⚠️ 主语是代词时不用倒装：Here it comes.

# 部分倒装句

只将助动词和谓语动词分离, 助动词提前。

| 触发条件 | 例子 |
| -------------------------- | --------------------------------------------------------------------------------------------------------- |
| 否定意义词置于句首         | Never before have I eaten such a delicious carrot.                                                        |
| only 置于句首              | Only in this way can we grow delicious carrots. / Only then did the rabbit meet the wolf.                 |
| if 虚拟语气省略（去掉 if） | Should I win the lottery, I would buy a huge pile of carrots.（= If I should win...）                     |
| so / neither / nor         | Rabbits love eating carrots. So do wolves. / The rabbit can't ride a bicycle. Neither / Nor can the wolf. / **Nor is it only** about the young. |

# 形式倒装（前置）

谓语动词不提前, 只把强调内容提到句首。

| 触发条件 | 例子 |
| ----------------------------------- | ------------------------------------------------------------- |
| 感叹句                              | What a delicious carrot it is!                                |
| the more...the more 比较句型        | The more carrots you eat, the healthier you become.           |
| however / whatever 引导让步状语从句 | However long this video is, you should watch it till the end. |
| as / though 引导让步状语从句        | Much as he likes the carrot, he doesn't want to eat it.       |

# 比较结构中的主语—助动词倒装

在正式的比较从句中, `than` 后面可以使用“助动词 / be 动词 / 情态动词 + 主语”的倒装结构。助动词代替前面已经出现过的重复动词, 避免重复。

| 倒装结构 | 还原语序 | 含义 |
| --- | --- | --- |
| `than did the students` | `than the students did` | 比这些学生…… |
| `than can the other groups` | `than the other groups can` | 比其他组能够…… |

> `Cheng and Wang then replicated these results in a second study, during which they had participants complete long multiplication questions by hand. Again, participants who watched the humorous video spent significantly more time working on this tedious task and completed more questions correctly **than did the students in either of the other groups**.`
>
> `did` 代替前面的 `completed`; 正常语序是 `than the students in either of the other groups did`。
