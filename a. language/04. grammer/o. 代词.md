# 基础知识

| 类型     | 代表词                  |
| -------- | ----------------------- |
| 人称代词 | I/me, he/him, she/her   |
| 物主代词 | my/mine, your/yours     |
| 反身代词 | myself, yourself        |
| 指示代词 | this/these, that/those  |
| 不定代词 | some/any, many/much     |
| 疑问代词 | who/whom, what, which   |
| 相互代词 | each other, one another |
| 关系代词 | who/which/that/as       |

代词 = pro（代替）+ noun（名词）= 替代名词的词。英语中代词的重要性远超中文——因为英语不喜欢重复名词：

> There is a rabbit. The rabbit is white. The rabbit is eating a carrot.（重复, 不自然）
> There is a rabbit. It is white. It is eating a carrot.（自然）

# 人称代词

替代前文提到的人或物, 防止重复。

> I saw the rabbit. → I saw him.

英文人称代词区分主格和宾格, 而中文不区分：

| 人称             | 主格（主语） | 宾格（宾语） | 形容词性物主代词 | 名词性物主代词 |
| ---------------- | ------------ | ------------ | ---------------- | -------------- |
| 第一人称单数     | I            | me           | my               | mine           |
| 第二人称单数     | you          | you          | your             | yours          |
| 第三人称单数(男) | he           | him          | his              | his            |
| 第三人称单数(女) | she          | her          | her              | hers           |
| 第三人称单数(物) | it           | it           | its              | its            |
| 第一人称复数     | we           | us           | our              | ours           |
| 第二人称复数     | you          | you          | your             | yours          |
| 第三人称复数     | they         | them         | their            | theirs         |

常见错误：You and I vs You and me

> You and I saw him.（做主格）
> He saw you and me.（做宾格）

❌ Me and my friends went there.
✅ My friends and I went there.

# 物主代词

| 形容词性物主代词（+名词） | 名词性物主代词（独立使用） |
| ------------------------- | -------------------------- |
| It is my carrot.          | The carrot is mine.        |
| It is your book.          | The book is yours.         |

# 反身代词

| 人称     | 反身代词   |
| -------- | ---------- |
| I        | myself     |
| you (单) | yourself   |
| he       | himself    |
| she      | herself    |
| it       | itself     |
| we       | ourselves  |
| you (复) | yourselves |
| they     | themselves |

> I saw myself in the mirror.
> The rabbit washed himself.

# 强调代词

与反身代词同形, 强调"亲自"：

> The rabbit washed the carrots himself.（强调是兔子亲自洗的, himself做状语）

# 相互代词

| 相互代词 | 解释 | 例子 |
| ----------- | -------------- | --------------------------- |
| each other  | 两者之间互相   | We should help each other.  |
| one another | 三者及以上互相 | We should help one another. |

# 指示代词

| 单数         | 复数          |
| ------------ | ------------- |
| this（这个） | these（这些） |
| that（那个） | those（那些） |

# 不定代词

| 数量不定代词 | 用法              | 搭配                        |
| ------------ | ----------------- | --------------------------- |
| many         | 许多              | 可数名词复数：many carrots  |
| much         | 许多              | 不可数名词：much water      |
| a few        | 一些（肯定）      | 可数名词复数：a few carrots |
| few          | 几乎没有（否定）  | 可数名词复数：few carrots   |
| a little     | 一些（肯定）      | 不可数名词：a little water  |
| little       | 几乎没有（否定）  | 不可数名词：little water    |
| some         | 一些（肯定句）    | some carrots                |
| any          | 一些（否定/疑问） | any carrots                 |

> Would you like some coffee?（请求期望肯定回答时用 some）
> The rabbit can eat any carrot.（any 表"任何"时可用于肯定句）

| 个体不定代词 | 用法                 | 搭配            |
| ------------ | -------------------- | --------------- |
| each         | 每一个（两者及以上） | 可单独使用      |
| every        | 每一个（三者及以上） | 必须跟名词      |
| either       | 两者中任一个         | either is good  |
| neither      | 两者中都不           | neither is good |
| both         | 两者都               | both carrots    |
| all          | 三者及以上都         | all carrots     |
| another      | 另一个（泛指）       | another carrot  |
| other        | 其他的               | other carrots   |

| 复合不定代词 | 指人               | 指物       |
| ------------ | ------------------ | ---------- |
| every-       | everyone/everybody | everything |
| some-        | someone/somebody   | something  |
| any-         | anyone/anybody     | anything   |
| no-          | no one/nobody      | nothing    |

⚠️ 复合不定代词作主语时谓语动词用单数：Everyone is here.
⚠️ 形容词修饰时后置：nothing important（不是 important nothing）

# 疑问代词

| 疑问代词 | 格 | 含义 | 例子 |
| -------- | ------ | ------ | -------------------------------------- |
| who      | 主格   | 谁     | Who ate the carrot?                    |
| whom     | 宾格   | 谁     | Whom did you see?（口语常用 who 代替） |
| what     | —      | 什么   | What did the rabbit eat?               |
| which    | —      | 哪一个 | Which is the best carrot?              |
| whose    | 所有格 | 谁的   | Whose is this carrot?                  |

whom 紧跟介词时不可用 who 替代：

> From whom did the rabbit get the carrot?
> Who did the rabbit get the carrot from?（介词放句末, 可用 who）

# 连接代词

引导名词从句：who, whom, whose, what, which

| 连接代词 | 从句类型 | 例子 |
| -------- | -------- | ----------------------------------------------- |
| who      | 宾语从句 | I don't know who you are.                       |
| what     | 主语从句 | What he said isn't true.                        |
| which    | 表语从句 | The important thing is which rabbit is smarter. |
| whoever  | 宾语从句 | The rabbit will follow whoever has carrots.     |
| whatever | 宾语从句 | The rabbit wants to eat whatever he likes.      |

加 -ever 表强调（"任何、一切"）。

# 关系代词

引导定语从句：who, whom, whose, which, that, as

| 关系代词 | 先行词 | 例子 |
| -------- | ------ | -------------------------------------------- |
| who      | 人     | The rabbit who became hungry ate a carrot.   |
| whom     | 人     | The rabbit whom I saw ate a carrot.          |
| whose    | 人/物  | The rabbit whose ears are long ate a carrot. |
| which    | 物     | The rabbit ate the carrot which I bought.    |
| that     | 人/物  | The rabbit ate the carrot that I bought.     |
| as       | 人/物  | The rabbit ate the carrot, as was expected.  |
