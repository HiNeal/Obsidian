# 强调概念

强调 = 通过各种方法把某句话中的某个信息凸显出来。

# 口气

口语中通过声音变化来强调。

重读单词：把需要强调的内容着重说出来。

叹词强调：用感叹词起强调作用。

特定语音/语调/语气强调：通过改变语调或语气来凸显信息。

# 书面格式

写作中通过排版来强调, 不改变句子结构。

| 方式 | 例子 |
| -------- | ---------------------------------------- |
| 粗体     | **This** is important.                   |
| 斜体     | *This* is important.                     |
| 下划线   | <u>This</u> is important.                |
| 全部大写 | This is VERY important.                  |
| 标点符号 | This is important! / This is important!! |

# 词汇强调

在句子中添加或替换词汇来强调, 不改变句子结构。


**添加强调词**

| 强调词 | 强调对象 | 例子 |
| --------------------------------- | ---------------- | -------------------------------------------------- |
| really                            | 动词             | Rabbits really like carrots!（兔子真的喜欢胡萝卜） |
| very                              | 副词/形容词      | I eat very fast.（我吃东西很快）                   |
| very                              | 名词（恰恰就是） | I miss the very beginning of the movie.            |
| just                              | 形容词           | This is just unbelievable!（这绝对难以置信）       |
| ever                              | 动词             | All I ever wanted is that carrot.                  |
| so                                | 形容词           | You are so careless!                               |
| absolutely / completely / totally | 形容词/动词      | I completely agree.                                |


**疑问词强调短语**

在疑问词后加短语表"到底、究竟"：

| 短语 | 强调对象 | 例子 |
| ------------ | -------- | ---------------------------------------- |
| in the world | 疑问词   | What in the world are you talking about? |
| on earth     | 疑问词   | What on earth are you talking about?     |
| the hell     | 疑问词   | What the hell are you talking about?     |
| the fuck     | 疑问词   | What the fuck are you talking about?     |


**重复单词**

> I eat very, very, very fast.


**使用助动词 do/does/did 强调谓语**

一般现在时和一般过去时中, 在动词前加 do/does/did：

> I **do** like carrots.（我真的喜欢胡萝卜）
> The rabbit **does** eat carrots.（兔子确实吃胡萝卜）
> I **did** see the rabbit yesterday.（我昨天确实看到兔子了）


**强调代词（反身代词表"亲自"）**

> The rabbit washed the carrots **himself**.

# 句式强调

通过改变句子结构来强调。


**倒装句强调**

否定词、only 等移到句首本身就是一种强调手段（详见倒装句笔记）。


**感叹句**

> What a delicious carrot it is!
> How lovely the rabbit is!


**it is/was...that 强调句型**

强调的部分放在 it is/was 和 that 之间。原始句：The rabbit ate the carrot in the kitchen yesterday.

| 强调成分 | 例子 |
| -------- | ------------------------------------------------------------------- |
| 主语     | It was **the rabbit** that ate the carrot in the kitchen yesterday. |
| 宾语     | It was **the carrot** that the rabbit ate in the kitchen yesterday. |
| 地点状语 | It was **in the kitchen** that the rabbit ate the carrot yesterday. |
| 时间状语 | It was **yesterday** that the rabbit ate the carrot in the kitchen. |

⚠️ 强调人时 that 可换 who/whom; 强调物/地点/时间时只能用 that。


**what 从句强调**

what 引导的主语从句 + be + 被强调的部分：

> **What the rabbit ate** was the carrot.（兔子吃的是胡萝卜）
> **What I need** is a good rest.（我需要的是好好休息）
