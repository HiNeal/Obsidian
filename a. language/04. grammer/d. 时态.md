# 基础知识

```plaintext
 v-s        人称变位
 v-ed       过去式变位
 v-ing      现在分词变位
 v-ed-en    过去分词形式标记, 规则动词和不规则动词的实际词形可能不同

+-------------------------------------------------------------------------------------------------------------------------------+
|               |                     |                |                                    |                                   |
|  动作 \ 时间  |        现在         |      过去      |                将来                |             过去将来              |
|               |      (Present)      |     (Past)     |              (Future)              |           (Past Future)           |
|               |                     |                |                                    |                                   |
|-------------------------------------------------------------------------------------------------------------------------------|
|               |                     |                |                                    |                                   |
|               |     一般现在时      |   一般过去时   |             一般将来时             |          一般过去将来时           |
|     一般      |        v/v-s        |      v-ed      |               will v               |              would v              |
|               |                     |                |        am/are/is going to v        |        was/were going to v        |
|               |                     |                |                                    |                                   |
|-------------------------------------------------------------------------------------------------------------------------------|
|               |                     |                |                                    |                                   |
|               |     现在进行时      |   过去进行时   |             将来进行时             |          过去将来进行时           |
|     进行      |   am/are/is v-ing   | was/were v-ing |           will be v-ing            |          would be v-ing           |
|               |                     |                |    am/are/is going to be v-ing     |    was/were going to be v-ing     |
|               |                     |                |                                    |                                   |
|-------------------------------------------------------------------------------------------------------------------------------|
|               |                     |                |                                    |                                   |
|               |     现在完成时      |   过去完成时   |             将来完成时             |          过去将来完成时           |
|     完成      |  have/has v-ed-en   |  had v-ed-en   |         will have v-ed-en          |        would have v-ed-en         |
|               |                     |                |  am/are/is going to have v-ed-en   |  was/were going to have v-ed-en   |
|               |                     |                |                                    |                                   |
|-------------------------------------------------------------------------------------------------------------------------------|
|               |                     |                |                                    |                                   |
|               |   现在完成进行时    | 过去完成进行时 |           将来完成进行时           |        过去将来完成进行时         |
|    完成进行   | have/has been v-ing | had been v-ing |        will have been v-ing        |       would have been v-ing       |
|               |                     |                | am/are/is going to have been v-ing | was/were going to have been v-ing |
|               |                     |                |                                    |                                   |
+-------------------------------------------------------------------------------------------------------------------------------+

时间：现在、过去、将来、过去将来(对于过去某一时间点而言的将来)

状态：一般（默认没有特别指出动作的状态信息）
      进行（动作正在进行的过程中）
      完成（动作已经完成了）
      完成进行（动作完成了一部分且还在进行）

英语中的将来时通过助动词 will 等构成, 动词本身没有将来时变位;
```

# 时态


```
                               A            B           C            D            E
                               ⌛-----------🕰️-----------🕒-----------⏰-----------🌅----------->
                          (过去的过去)    (过去)       (现在)      (将来)    (将来的将来)

```


## 现在

| 时态 | 说明 | 例子 |
| -------------- | ------------------------- | ------------------------------------------------------------------ |
| 一般现在时     | C 的事实 / 习惯 / 预计    | The rabbit eats carrots.                                           |
| 现在进行时     | C 此刻正在进行            | The rabbit is eating carrots.                                      |
| 现在完成时     | B 完成, 暗含对 C 的影响   | The rabbit has eaten all the carrots, so there's nothing left now. |
| 现在完成进行时 | B 开始, 持续至 C 且未结束 | The rabbit has been eating carrots.                                |

## 过去

| 时态 | 说明 | 例子 |
| -------------- | ------------------------- | -------------------------------------------------------------------------------------------- |
| 一般过去时     | B 时发生                  | The rabbit ate carrots yesterday.                                                            |
| 过去进行时     | B 某刻正在进行            | The rabbit was eating carrots at 3pm yesterday.                                              |
| 过去完成时     | A 完成, 暗含对 B 的影响   | The rabbit had eaten five carrots for lunch, so it wasn't hungry at all yesterday afternoon. |
| 过去完成进行时 | A 开始, 持续至 B 且未结束 | The rabbit had been eating carrots for two hours when I arrived.                             |

## 将来

| 时态 | 说明 | 例子 |
| -------------- | ------------------------- | ------------------------------------------------------------------------------------ |
| 一般将来时     | D 时将发生                | The rabbit will eat carrots.                                                         |
| 将来进行时     | D 某刻正在进行            | The rabbit will be eating carrots at 3pm tomorrow.                                   |
| 将来完成时     | D 前完成, 暗含对 D 的影响 | The rabbit will have eaten carrots by 3pm tomorrow, so it won't be hungry at dinner. |
| 将来完成进行时 | C 开始, 持续至 D 且未结束 | The rabbit will have been eating carrots for two hours by 2pm tomorrow.              |

## 过去将来

| 时态 | 说明 | 例子 |
| ------------------ | ------------------------ | --------------------------------------------------------- |
| 一般过去将来时     | 站在 B, 其后将发生（≥C） | I said I would eat a carrot for lunch.                    |
| 过去将来进行时     | 站在 B, 其后某刻正在进行 | I said I would be eating a carrot at 1PM tomorrow.        |
| 过去将来完成时     | 站在 B, 其后某时前完成   | I said I would have eaten a carrot by 1PM tomorrow.       |
| 过去将来完成进行时 | 站在 B, 持续至其后某时   | I said I would have been eating lunch for 2 hours by 1PM. |
