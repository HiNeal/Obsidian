# 破局法则

## 实战法则

| 实战法则     | 具体做法                                                                                                    |
| :------- | :------------------------------------------------------------------------------------------------------ |
| **预读阶段** | 1. 预判词性: 用尽时间读题(填空题前后都读),预判词性, 模拟专词发音<br>2. 高亮重点: 优先高亮名词, 并留意限制词, 时间状语<br>3. 反推语料: 能够在预读阶段就可以反推听力语料的逻辑; |
| **听题阶段** | 1. 所有选项可能都会提到,因此留意否定/逻辑转折/虚假一致;<br>2. 听到的信息有可能正确,也有可能会被被后文推翻;<br>3. 留意是否是虚假同意;                          |
| **做题阶段** | 1.根据音频在题目不断校准, 绝不纠缠;<br>2.填空题如一时间无法写出单词, 写大概标记发音;                                                       |
| **检查阶段** | 1. 拼写检查(单词本身 & 名词单复数)                                                                                   |

## 常见陷阱

| 陷阱类型              | 出题特征                                                                               |
| :---------------- | :--------------------------------------------------------------------------------- |
| **拼写错误**<br> (个人) | 单词本身 & 名词单复数<br>(填空题)                                                              |
| **听音偏差**<br> (个人) | 听成发音相近的另一个词<br>(填空题)                                                               |
| **做题节奏**<br> (个人) | 预读阶段没有做好 & 纠缠题目<br>(所有题型)                                                          |
| **选项全现**          | 所有选项都提及, 但存在反义和转折, 需要听清具体态度<br>(单选题)                                               |
| **逻辑转折**          | 刚出现的信息被后文推翻,留意 `although, but, however, used to be`<br>(填空题, 单选题)                  |
| **顺序倒置**          | 空格后文的信息先出现, 空格前后的内容都需要留意<br>(填空题)                                                  |
| **虚假一致**          | 双人只回 `Mm ...` 不代表一致,题干含 `agree, both` 时, 找双方明确的 `Me too, Yeah, I ... too`<br>(多选题) |
| **评价干扰**          | 地图题录音夹杂评价, 只留方位信息<br>(地图题)                                                         |


# 题型矩阵

| 题型 | 要点 |
| :--- | :--- |
| **填空题** | 1. 先看字数限制(如 `ONE WORD AND/OR A NUMBER`)和空格词性, 名词前注意 `a / an`<br>2. 星期、月份、日期、国家名称和大数字要会听会拼<br>3. Part 1 读一遍即可, 时间留给 Part 2<br>4. Part 4 难度最高, 开始前最好已读完约四分之一的题<br>5. 预判改写, 如 `spoon made of wood` 对应 `wooden spoon`<br>6. 自然段之间的停顿是大要点切换, 句间停顿是小点换行; `specifically, amazingly` 后常有核心信息; 不能只靠停顿, 还要看语法 |
| **单选题** | 1. 题干比选项重要, 先读题干, 再抓选项的基准词和区别点<br>2. 选择题开始前最好已读完约一半, 有时间每题读两遍<br>3. 边听边读边选会分心, 靠听力实力 |
| **多选题** | 1. 读题同单选题, 纵向比较选项, 抓关键词<br>2. 题干含 `agree, both` 时, 找双方明确一致的表达 |
| **匹配题** | 1. 先按题目定位, 再看选项; 确定一个就划掉(机考直接拖入)<br>2. 预判改写, 如 `fast movement` 对应 `rapid movement`<br>3. 选项多会分散听音, 靠听力实力 |
| **地图题** | 1. 地点、方位和移动表达要专项积累并背熟<br>2. 先读地点名词并模拟发音, 看清图例; 不熟东西南北就在图上标注<br>3. 用眼神、笔或手指跟着路线走, 地点之间的停顿用来跟路线 |

# 其他

- 有效精听: 填空题的精听逻辑是听写, 选择题的精听逻辑是听意思(放的同时想意思)
- 词汇: 基本都是四级词汇,不用画特别长时间去看场景词
- 纠错: 有效精听 + 精听错题(错题就是宝贝,单句精听,听 10 遍知道听懂为止)
-  长选择和匹配: 核心原因其实是长选择和长匹配会分散我们的精力去看选项,导致耳朵的注意力占比太小了, 这里解决方案: 题目由于是英语原词定位,需要读英文在心里过发音; 而选项要用中文审题,心里面过中文意思,然后缩短意思,让我们耳朵的注意力能够大一些; 主要我们听到题目了,就靠听力逻辑去蹲答案, 长匹配做成短匹配 长选选择做成短选择
