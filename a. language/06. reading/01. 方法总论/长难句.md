# 核心概念

天下本无英语, 只有介短、从句、非谓语! 破解长难句的关键, 在于识破句中的这三类"较长修饰成分"。

| 维度 | 汉语 | 英语 |
| -------- | ---------------- | -------------------------------------------------- |
| 主干成分 | 与英语基本一致 | 与汉语基本一致, 另有若干固定句型 |
| 修饰成分 | 多为前修 | 较短修饰成分放在被修饰词前面, 较长修饰成分放在被修饰词后面 |

核心规律: 英语的较长修饰成分被放在了被修饰成分的**后面**(后修), 中文译文需要把它挪回前面(前修)。

# 三长修饰成分

| 类型      | 定义                      | 结构                 | 起始标识                 |
| ------- | ----------------------- | ------------------ | -------------------- |
| 介词短语    | 从介词开始到名词结束, 表达独立完整含义的结构 | 介词 + (修饰语) + 名词    | 介词                   |
| 从句      | 由引导词引导的主谓结构             | 引导词 + 主语 + 谓语 + 宾语 | 引导词(有时可省略)           |
| 非谓语动词短语 | 由非谓语动词开头, 表达独立完整含义的结构   | 非谓语动词 + 名词 + 副词    | to do / doing / done |

# 介词短语

从**介词**开始, 到**名词**终止。

| 例子 |
| ------------------------------ |
| at home |
| in the school |
| beyond my wildest imagination |
| during my happy childhood |
| over the last few years |

# 从句

常见引导词: that, who, whom, when, why, where, how, which, if, although, because, than ...

从句一定从**引导词**(有时可省略)开始, 有以下四种终止标识:

| 终止标识 | 例子 |
| ---------------------- | ------------------------------------------------------------------------- |
| 到句尾终止 | LiHui is a teacher (who teaches English). |
| 到句中的逗号终止 | (When I was young), I listened to the radio. |
| 到下一个修饰成分终止 | I will invite Yaoming (who was a top basketball player) (to Beijing). |
| 到下一个谓语动词终止 | Yaoming (who was a top basketball player) is studying in Shanghai. |

# 非谓语动词短语

非谓语动词是动词在句中"不作谓语"时的变化形式, 包括动词不定式(to do)、动名词(doing)和分词(现在分词 doing, 过去分词 done)三类。非谓语动词短语一定由这三类开头, 同样有四种终止标识:

| 终止标识 | 例子 |
| ---------------------- | ------------------------------------------------------------ |
| 到句尾终止 | LiHui is a teacher (teaching English). |
| 到句中的逗号终止 | (To improve my English), I often chat with foreigners. |
| 到下一个修饰成分终止 | Jack walked in, (waving confidently) (to the audience). |
| 到下一个谓语动词终止 | We, (singing a happy song), rode to school. |

# 平行并列结构

由并列词连接两个及以上**含义相似、结构相同**的并列项所构成的结构, 简写形式为 `A and B`、`A, B and C`。

| 并列词 | 释义 |
| ------------------------ | -------------------- |
| and | 和 |
| or | 或 |
| but | 但是 |
| as well as | 以及 |
| both ... and ... | 两者都 |
| either ... or ... | 要么 ... 要么 ... |
| neither ... nor ... | 既不 ... 也不 ... |
| not only ... but also ... | 不仅 ... 而且 ... |

核心原则: 只要满足含义相似、结构相同, 任意语言成分都可以构成并列; 阅读长难句时, 关键要分清**并列对象**。

简单举例: mom and dad; not only Bob but also James; Tom, Dick and Henry.

| 并列成分 | 例句 | 并列项 | 译文 |
| ------------ | -------------------------------------------------------------------------------------------------- | ----------------------------------------------- | -------------------------------------------- |
| 名词 | Tom and Jerry are friends. | Tom, Jerry | 汤姆和杰瑞是好朋友。 |
| 形容词 | Mr. Smith is a kind, patient and knowledgeable English teacher. | kind, patient, knowledgeable | 史密斯先生是一位善良、耐心且学识渊博的英语老师。 |
| 副词 | You are supposed to answer the following questions quickly and accurately. | quickly, accurately | 你应当快速且准确地回答下面的问题。 |
| 动词 | With the Internet, people can not only play computer games but also do online shopping. | play computer games, do online shopping | 有了互联网, 人们不仅可以玩电脑游戏, 还能网购。 |
| 介词短语 | And that government of the people, by the people and for the people shall not perish from the earth. | of the people, by the people, for the people | 民有、民治、民享的政府永世长存。 |
| 从句 | I've finished reading the book which is written by Mo Yan and which you lent me last month. | 两个 which 定语从句, 共同修饰 the book | 我已经读完了那本莫言写的、你上个月借给我的书。 |
| 非谓语动词 | Singing and laughing, we headed to the park. | Singing, laughing(现在分词作伴随状语) | 我们一路欢歌笑语, 朝公园走去。 |
| 整句 | The children can go with us or they can stay at home. | or 连接两个完整的简单句 | 孩子们可以跟我们一起走, 也可以留在家里。 |

# 括号法三步拆解

| 步骤          | 操作           | 要点                        |
| ----------- | ------------ | ------------------------- |
| Step 1 预处理  | 给句子做标记, 切分成分 | 三长加括号, 并列词加方框, 并列项加三角这种方法 |
| Step 2 逐段直译 | 一个括号翻译一段     | 按括号顺序翻译, 暂不调整语序           |
| Step 3 调整语序 | 理顺中文语句       | 后修变前修, 少量增删词语             |

# Step 1 预处理

| 标记对象                             | 标记符号  | 示例            |
| -------------------------------- | ----- | ------------- |
| 三长(长介词短语、长非谓语、长从句)               | `( )` | (on the desk) |
| 并列词(and / or / but / as well as) | `[ ]` | [and]         |
| 并列项 A, B                         | 三角 △  | △A [and] △B   |

- 注 1: 找并列项时, 先锁定 B, 再反向匹配 A。
- 注 2: 出现下一个修饰成分时, 立刻结束上一个修饰成分, 不必等到上一修饰自行完结。

| 例句(预处理后) | 译文 |
| ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| I like the box (on the desk) [and] the flower (in your hand) (which you promised) (to give me). | 我喜欢桌上的那个盒子, 还有你手里的那朵花, 也就是你答应过要送给我的那朵。 |
| LiHui is a teacher (teaching English) (in Beijing) (which is the capital) (of China). | 李辉是一名在中国首都北京教英语的教师。 |
| They will be able (to clear away the mystery) (of mathematics) [and] face their studies (with more confidence) (than they ever imagined). | 他们将能够揭开数学的奥秘, 并且以远超自己想象的信心去面对学业。 |

# Step 2 逐段直译

- 操作规则: 按括号顺序逐段翻译, 暂时不用调整语序。
- 语言逻辑: 英文是"挂钩语言", 每个括号内的核心词为"挂钩词", 可以通过对挂钩词提问, 把零散的内容串联起来。

| 原句 | 直译草稿 |
| ------------------------------------------------------------------------------------ | ------------------------------------------------ |
| LiHui is a teacher (teaching English) (in Beijing) (which is the capital) (of China). | 李辉是老师 - 教英语 - 在北京 - 它是首都 - 中国的 |

# Step 3 调整语序

- 核心规则: 后修变前修(把英文后置定语改为中文前置定语), 少量增删词语, 让语句通顺。

| 版本    | 译文                     |
| ----- | ---------------------- |
| 定语前置  | 李辉是一个在中国首都北京教英语的老师。    |
| 拆分为短句 | 李辉是一名老师, 他在中国的首都北京教英语。 |

# 巩固练习

| 句子 | 预处理 | 标记说明 |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- |
| 1 | Hello. It's one (of the first words) (we learned) (as babies); [yet] it's one (of the last words) (we think) (to use) (as adults). | yet 为并列连词, 连接前后两个分句 |
| 2 | The Department (of Agriculture) has programs (aimed) (at developing more farmers) [and] (at increasing interest) (in locally grown food). | 方框标出 and, 两个 at 引导的介词短语为并列项 |
| 3 | If you started (to dry clothes) (in the morning) [and] forgot (to take them out), you can go (to your phone) [and] restart your dryer. | 两个 and 均用方框标出, 分别连接两组并列动词 |
